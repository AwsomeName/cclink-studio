# ADR 0023：Studio 自主任务在启动前选择可用 Agent

- 状态：accepted（2026-11-11 用户明确要求检查所有同类任务并自动选用可用 Agent）
- 补充 ADR 0022：自主任务允许在执行前选择已配置的备选；显式聊天和需要续接的原生 Session 不自动迁移。

## 用户验收

未配置 Claude Key、Codex 已登录时，定时任务、文章发布启动、图片调研、视频智能分镜/口播和
账目 AI 分类均应能使用 Codex。Codex 未安装或未登录、Claude 已配置并可启动时，同一类新任务
应自动选择 Claude。两者都不可用时展示两者的原因，任务不得假成功；取消或退出后不得迟到执行。
文章发布只验收启动选择与执行身份，本决策不授权任何具体账号或文章的公开提交。

## 选择与边界

- AgentBridge 是唯一选择入口；调用方声明 main-owned 自动选择，不新增 renderer 参数、设置、
  IPC、任务账本、调度器或跨供应商会话迁移。
- 优先 Codex：复用既有 app-server 只读探测，按目标工作空间检查文件登录与配置；探测总预算
  4 秒，不发模型请求、不开放工具、不执行登录、不读取或迁移钥匙串。失败时检查 Studio 已保存
  的 Claude Key、已解析运行时及 executable；不继承本机 Claude 订阅、ACP 或远端实验服务。
- “可用”表示启动前置条件满足，不是网络、额度或任务成功保证。选定后使用原有权限和工具
  allowlist 执行一次；模型请求开始后不换 Agent 重试，以免重复发布、写入或其他副作用。
- 活动运行和需要续接的原生 Session 保持绑定。文章发布、图片调研的后续 operation 虽复用
  conversation ID，但 main 明确请求 `sessionId: null`，会释放旧 Session 信任并为全新运行重新选择；
  不续接旧引擎 Session，不重跑已有 operation。任务选择准备期归既有 run 账本所有；临时 AbortController
  只拥有探测资源，取消、关闭会话和退出均释放。配置切换和重复发送不得覆盖准备中的选择。
- 文章发布在 onRunPrepared 中读取最终 Agent 身份，再登记 WebAffair Runtime binding；不得提前
  把旧默认身份写入事务，也不得在工具开放后换身份。WebAffair 继续唯一拥有发布状态。
- 诊断记录 run、选择结果和探测失败分类，不记录凭证、账号身份、任务正文或提供商原始错误。

## 验证与降级

覆盖 Codex 优先、Claude 备选、全部不可用、目标工作空间配置、取消/退出/并发配置切换、已有
绑定保留、任务工具限制及文章发布身份关联。真实 Electron 验证定时任务和内部文本生成；
本地拒绝端点验证 Claude 自动备选的实际调用链。真实公开发布和用户正式任务另行验收。
