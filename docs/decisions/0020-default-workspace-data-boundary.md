# ADR 0020 默认工作空间与业务资料边界

- 状态：accepted
- 日期：2026-11-03；第一批实施与架构核对：2026-11-04
- 依据：用户确认默认工作空间与工作空间内统一资料目录的方向，并要求详细设计和实施计划。
- 关联：[产品设计](../features/default-workspace-data-design.md)、[实施计划](../features/default-workspace-data-development-plan.md)。

## 问题

首次启动没有可直接保存业务资料的本地目录。公司与账目已在空间内保存，网页事务仍存中央文件；目录复制会产生新空间身份，而公司数据库仍引用原身份。用户难以判断资料在哪里、备份包含什么，以及复制后是否会继续执行原任务。

本决策记录默认入口、事务持久化和移动复制的长期边界，不改变架构宪法的唯一状态所有者、免登录或最小权限规则。Home 保留全局 Tab 语义，global 保留未归档语义；默认空间是普通本地空间。

## 决策

1. 首次启动提供默认本地空间；有效历史选择与显式未归档优先，原路径失效时不静默创建替代空目录。
2. 公司、账目、事务和任务定义归属空间；各自服务保持唯一 owner，不合并为全模块数据库或通用 orchestrator。
3. WebAffairService 逐空间把中央事务迁入空间目录，采用有界迁移记录、兼容读和切换后的单写。旧源与备份保留，迁移成功不改变发布结果。
4. ADR 0014、0016 继续有效。网站账号和矩阵仍是本机全局资源，任务保存显式引用；Profile、Session、凭证和执行授权不随业务目录复制。
5. 任务定义、文件产物和只读历史可携带；调度启用、权限确认、活跃队列和去重账本仍是本机事实，不能作为恢复后自动执行的依据。
6. 移动保持唯一身份；副本或跨设备默认生成新身份，重建业务引用，运行及提交授权不继承。身份判定和维护动作复用原 Workspace 基础层。
7. 内部业务数据默认不随 Git 共享，仅保留既有显式共享任务例外；完整资料备份独立说明范围与缺口。
8. 保留当前兼容身份文件，新增接口使用 workspace 命名；身份文件重命名不成为默认入口的前置重构。

## 不变量

- 默认创建失败或任一业务模块故障不阻断其他本地能力；远程初始化仍按需触发。
- 文件格式、IPC、迁移结果与错误先定义共享 schema；主进程验证 sender、路径与稳定归属。
- WebAffair 独占发布进度，ScheduledTaskService 独占调度；不引入第二状态源、短 Run 调度或完整 operation 账本。
- 原始发布回执可以作为历史保存，未知提交结果只能核验，不能迁移后自动重发。
- 不使用系统钥匙串；不迁移云服务或独立 Agent runtime。

## 备选方案

- 维持中央事务文件，只增加默认目录：可作为第一批增量，不能满足后续业务资料迁移目标。
- 把账号、Cookie、所有运行状态一并复制：会继承错误身份或重复执行，且破坏全局账号边界，不采用。
- 统一为一个数据库或新的存储框架：扩大跨域依赖和故障范围，本轮不采用。
- 全面改名身份字段后再交付：延迟可见结果；兼容命名沿用，后续单独迁移。

## 风险与影响

主要风险是中央到目录的提交中断、复制后的身份和引用冲突、后台运行写入旧位置，以及用户把程序降级误当作数据回滚。具体提交点、失败行为及受支持的回退操作由实施计划规定。跨数据库备份只承诺清单中已核验的各域快照，不宣称共同原子性。

## 迁移计划

先交付默认入口及原功能纵向验收，再迁移事务分区和旧关联，最后交付备份、移动及副本恢复。每批保留旧源和故障证据，单独报告用户能力及工程门禁。

## 回收或复审条件

- 需要网站账号按公司隔离、团队协作、云同步或退出 App 后持续调度；
- 事务分区化无法保持现有后台运行、恢复日志或唯一写入语义；
- 真实数据备份证明当前跨域快照策略无法保持必要引用一致；
- 需要扩展主目录之外的路径权限或迁移本机去重账本。

## 验证

按[验收矩阵](../testing/default-workspace-data-acceptance.md)分别记录首次启动、旧数据原记录下钻、迁移中断、切换与重启、备份恢复、移动副本、权限隔离和发布专项结果。本决策已按唯一 owner、生命周期和权限边界完成第一批实施核对；第一批真实 App 自动验收通过，真人签收待执行，第二、第三批尚未实现。
