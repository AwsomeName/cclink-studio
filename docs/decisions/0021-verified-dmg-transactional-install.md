# ADR 0021：从可信 DMG 自动安装并重启

- 状态：accepted（实现授权；两轮正式升级验收是产品完成条件，不阻止自动门禁通过后的公开发布）
- 日期：2026-10-08
- 取代：ADR 0005 的 ZIP 安装输入要求；其单状态所有者、信任校验与回滚要求继续有效。

## 用户验收

安装在可写目录的官方 arm64 Studio 检查并下载新版 → 点击“安装并重启” →
处理未保存文档和运行任务 → 确认 → 应用自动退出、替换、重新打开；版本正确、
工作空间与标签恢复。取消、权限不足、损坏候选、退出失败或新版启动失败时旧版仍可启动。
现有 0.1.104 不能自行获得新的安装代码，需要手工安装一次包含本功能的基线版本。

## 决策和评审

继续使用 Manifest v3 的唯一 arm64 DMG，复用 UpdateCache 完整性复验和
MacDmgVerifier 的 Team ID、Bundle ID、版本、公证和架构检查。
在只读挂载期间将唯一候选复制到安装目录的私有临时目录，再次验证复制后的应用。
不新增 Provider、下载器、ZIP 格式或更新产品状态所有者。

独立原生 Helper 无网络能力，只接受主进程生成的受限权限事务；编译进入 Resources，
由正式包的 Developer ID 签名和公证链覆盖。它等待旧进程正常退出后，使用 macOS
同卷原子目录交换替换应用。应用路径始终存在，交换后的临时目录保存旧版。
Helper 监控新版启动回执；超时恢复旧目录并启动旧版。事务证据独立落盘，崩溃后
保留旧版和可恢复路径；不得通过删除原应用再复制来实现替换。

UpdateService 负责安装准备、短期一次性确认令牌、缓存复验与安装状态。
工作现场保护复用 renderer 工作空间 flush 和主进程领域服务 flush。未保存内容、
活动任务不能被安装自动丢弃；安装期间冻结交互并重新检查，任一失败不退出。
不申请管理员权限，不修改系统钥匙串，不关闭 Gatekeeper。

## 风险、实验与门禁

在两个公开签名、公证 arm64 包的隔离副本上先验证交换、启动和回滚，测试无写权限、
候选签名不匹配、父进程未退出、启动回执超时及 Helper 异常中断。
实验不得替换用户实际 /Applications 应用或使用真实工作数据。
未经真实签名实验验证的安装器不启用生产按钮；源码测试和开发 UI smoke 不替代
首次正式基线及后续两轮升级验收。

## 替代与回收

直接接入 autoUpdater/electron-updater 会复制发现、下载和缓存状态，继续拒绝。
若原子交换或回滚实验失败，停在可信 DMG 手工安装，不削弱校验上线。
安装失败保留可信 DMG；清理只能针对当前事务的临时目录，成功启动前保留旧版。
