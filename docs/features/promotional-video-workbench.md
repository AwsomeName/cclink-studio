# 宣发视频工作台

> 产品与架构提案，尚未实现。最后更新：2026-08-14。

## 结论

CCLink Studio 可以增加一个原生“宣发视频”工作台，把稿件、分镜、素材、AI 生成、字幕、
配音、预览和导出串成一个用户可完成的纵向闭环。

模型服务首版只使用云端视频生成 API，并优先接入中国内地可用、人民币结算、支持国内主体
开票和稳定异步任务的国内 Provider；不安装或运行本地视频模型，不把 ComfyUI、Python、GPU、
显存或 custom nodes 作为产品前置条件。Studio 自己拥有稿件、分镜、素材、任务、合成和导出；
云端 Provider 只负责按单个场景生成候选视频片段。

首版不做 Premiere、DaVinci Resolve 或 CapCut 级通用多轨编辑器。首版采用场景卡片式
时间线，优先让用户从一篇真实稿件生成、修改、预览并导出一条 30～45 秒的宣发视频。

## 用户端到端验收

首个产品里程碑必须让用户在真实 Studio 中完成以下动作：

1. 在本地工作空间选择一篇 `.md` 或 `.markdown` 稿件，新建“宣发视频”。
2. 选择 16:9、9:16 或 1:1，设置目标时长、平台、品牌色、Logo 和结尾 CTA。
3. 让 Agent 把稿件拆成 4～8 个场景；每个场景显示旁白、字幕、画面说明、素材搜索词、
   AI 生成提示词和预计时长。
4. 在产生付费生成调用前检查并修改分镜，并明确确认 Provider、模型、镜头数量和预计费用
   或“费用暂不可估算”的事实。
5. 为每个场景从以下来源选择素材：工作空间文件、本机导入、素材搜索、现有图片生成、
   文生视频或图生视频。
6. 对单个失败或不满意的场景执行替换、重新搜索或重新生成，不重做整条视频。
7. 在场景时间线中调整顺序、时长、字幕、转场、背景音乐和音量，得到可播放预览。
8. 导出一个可播放的 MP4、一份字幕文件和一份素材来源清单；关闭并重启 Studio 后仍能
   重新打开工程、查看任务终态和继续修改。

只有上述真实应用动作通过，才可以宣称“稿件生成宣发视频”完成。只有 Provider mock、单元
测试、云端 API 连通或单个片段生成成功时，只能声明相应工程门禁通过。

## 产品边界

### 首版包含

- Markdown 稿件导入和版本快照；
- AI 分镜与场景卡片；
- 16:9、9:16、1:1 三种画幅；
- 本机素材导入和工作空间素材选择；
- 至少一个图片/视频素材搜索 Provider；
- 复用现有 `ImageGenerationService` 生成图片；
- 至少一个真实云端 `VideoGenerationProvider` 完成文生视频和图生视频中的一种；
- 旁白文案、字幕、Logo、CTA、简单转场和背景音乐；V0 可导入用户已有旁白音频，但不包含
  云端 TTS、录音或自动字幕对齐；
- 场景级预览、替换、重试和最终 MP4 导出；
- 素材来源、生成任务和用量事实记录。

### 首版不包含

- 通用多轨、关键帧、蒙版、复杂调色和插件特效编辑器；
- 自动发布到社交平台；
- 未经用户确认的批量付费生成；
- 本地视频模型、ComfyUI、Python、模型下载和 GPU 管理；
- 无法追溯来源或使用权的网络素材静默下载；
- CCLink 登录、远程服务或桌面 entitlement 前置条件。

## 用户流程

```text
稿件 / Markdown
  → AI 分镜
  → 用户检查场景、费用和品牌信息
  → 搜索 / 导入 / 生成每个场景素材
  → 场景卡片式时间线
  → 字幕 / 配音 / 音乐 / Logo / CTA
  → 本地预览
  → 导出 MP4、字幕和来源清单
```

## 产品形态

宣发视频是工作空间内的一种持久工程，通过原生 `media-production` Workbench Tab 打开。用户
面对的是视频生产流程，不是模型参数或通用剪辑软件。

### 新建向导

新建宣发视频时只收集形成分镜所需的信息：

- 稿件：选择 Markdown、粘贴文本或从当前编辑器创建；
- 发布目标：小红书/抖音竖屏、视频号、B 站/官网横屏或自定义；
- 画幅和目标时长；
- 受众、语气和期望行动；
- 品牌色、Logo、字体和结尾 CTA；
- 可选参考图片、产品截图、已有视频和旁白音频。

### Workbench Tab

单个 Tab 使用四区布局：

1. **顶部阶段条**：简报、分镜、素材、成片、导出；只表达当前完成度，不复制工程状态。
2. **左侧场景列表**：场景缩略图、时长、素材类型、生成状态和错误；支持排序和复制。
3. **中央预览**：播放当前场景或整条视频，支持时间定位，但首版没有任意多轨编辑。
4. **右侧检查器**：编辑旁白、字幕、提示词、素材、时长、转场、品牌覆盖和单场景操作。

底部只在有长任务时显示任务抽屉：任务 ID、Provider、模型、进度、耗时、费用事实、取消/
重试和错误。任务抽屉关闭后任务仍由主进程继续拥有。

### 场景素材选择

每个场景提供四个互斥主入口：

- **搜索素材**：查找并添加有来源记录的图片或视频；
- **工作空间素材**：使用产品截图、录屏、Logo 或用户已有视频；
- **生成图片**：复用现有图片 Provider，随后使用平移、缩放等确定性动效；
- **生成视频**：调用云端视频 API，可以文生视频，也可以把选中的图片作为首帧或参考图。

AI 可以给每个场景推荐入口，但不能静默产生付费视频任务。宣发视频默认混用真实素材、产品
画面、生成图片和少量生成视频，不追求整条视频全部由模型生成。

### 场景模型

每个场景至少包含：

- 稳定 `sceneId`；
- 旁白文本和屏幕字幕；
- 画面目标与生成提示词；
- 素材搜索词；
- 目标时长和画幅；
- 当前选中素材引用；
- 备选素材引用；
- 转场和简单运动参数；
- 生成任务引用、错误与重试历史；
- 用户确认状态。

首版使用场景卡片，不提供任意轨道结构。场景之间可以排序；场景内部最多拥有一个主视觉、
一个旁白、一个字幕层、一个品牌覆盖层和一个背景音乐引用。只有真实用户证据证明这一模型
不足时，才扩展为通用多轨时间线。

## 素材来源

### 本地素材

- 从工作空间选择图片、视频、音频和 Logo；
- 从系统文件选择器导入；
- 保留原文件，工程资产使用内容哈希和稳定引用；
- 不把大视频或生成输出存入 renderer 状态。

### 素材搜索

素材搜索使用可替换 Provider contract。Pexels 图片与视频 API 只是候选之一，首个真实 Provider
必须另外通过中国内地网络稳定性、授权条款、归因要求和下载可靠性验收，不能成为工程硬依赖。
搜索结果只是远端候选，用户执行“添加到工程”后才下载。
每个下载素材必须保存：

- Provider 和远端素材 ID；
- 原页面 URL、作者与作者页面；
- 下载时间和原始文件 URL；
- 当时可见的归因/使用规则摘要；
- 本地文件哈希；
- 用户选择记录。

搜索 UI 必须显示 Provider 链接和作者归因，不能复制素材网站的核心图库体验。

### AI 生成素材

- 图片生成继续由现有 `ImageGenerationService` 唯一拥有；
- 新增 `VideoGenerationService` 和有界 Provider Adapter；
- 每个输出记录 Provider、模型、task/job ID、prompt、参考素材、画幅、时长、文件哈希、
  用量和终态；
- 视频生成失败不影响本地素材、图片生成和其他 Studio 能力。

## 云端模型服务

云端模型服务只拥有 Provider 请求与返回事实，不拥有视频工程和场景状态。统一
`VideoGenerationProvider` contract 至少包含：

- `getCapabilities()`：模型、文生/图生/参考素材、时长、画幅、分辨率、音频、取消和费用能力；
- `createTask()`：提交一个场景 revision，返回稳定 Provider task ID；
- `getTask()`：查询排队、运行、成功、失败、取消或未知状态；
- `cancelTask()`：Provider 支持时取消，不能把本地取消按钮伪装成远端已取消；
- `downloadResult()`：只下载受信 HTTPS 输出，校验类型、长度和内容；
- `estimateCost()`：Provider 能提供时返回估算，否则明确标记不可估算。

每个请求固定保存 Provider、模型、提示词、参考素材哈希、场景 revision、画幅、时长和提交时间。
结果返回时如果场景已修改，输出进入备选素材，不自动覆盖用户的新选择。

## Provider 策略

`VideoGenerationProvider` 应允许逐步增加：

- `volcengine-jimeng-video`：首个纵向闭环候选；复用现有即梦 AK/SK、火山签名器、异步任务
  和错误分类基础，逐项接入经过真实验收的即梦/Seedance 视频能力；
- `tencent-mps-video`：国内聚合 Provider 候选；通过腾讯云媒体处理的一套 API 使用混元、可灵、
  海螺和 Vidu 等模型；
- `aliyun-wanxiang-video`：阿里云百炼/通义万相；支持中国内地部署、文生、图生、首尾帧、参考
  生视频、视频编辑和数字人等能力；
- `vidu-video`：生数科技 Vidu 直连；覆盖文生、图生、首尾帧和参考生视频；
- `minimax-hailuo-video`：MiniMax 海螺直连；覆盖文生、图生、首尾帧和主体参考；
- `openai-video`、`runway`、`vertex-veo`：后续国际 Provider，不进入首个国内纵向闭环；
- 后续其他经过验收的 Provider。

首版只实现一个真实国内云端 Provider，但先冻结统一 contract。Provider 能力必须显式报告：

- 文生视频、图生视频、参考图、参考视频、音频驱动；
- 支持的时长、画幅、分辨率和模型；
- 是否提供进度、取消、恢复、用量与费用估算；
- 凭证状态、内容审核限制和当前不可用原因；
- 服务地域、素材静态存储地域、下载地址有效期和数据出境事实；
- 计费币种、发票主体、并发限制和可查询的实际用量。

首个 Provider 选择顺序不是只比较模型榜单，而是依次验证：

1. 团队能取得真实账号、开通权限和低额度测试预算；
2. 中国内地网络稳定，任务提交、查询和下载无需额外网络条件；
3. 至少完成图生视频或文生视频一个真实场景闭环；
4. 错误、内容审核、限流、余额和并发状态可以结构化分类；
5. 输出能及时下载到本地，Provider 短期 URL 过期不丢资产；
6. 价格和使用记录足以在确认卡和用量账本中展示事实。

Agent API Key、图片 Provider Key、视频 Provider Key 和素材搜索 Key 是不同凭证，不得互相
复用或进入 renderer 全量状态。全部由 `CredentialService` 保存和按用途解析。

## 合成与导出

生成模型只产生素材片段，最终宣发视频仍需要确定性的合成层：

- 图片/视频裁剪、缩放和统一画幅；
- 场景拼接和简单转场；
- 字幕、Logo、标题、CTA；
- 旁白、音乐混音、淡入淡出和基础 ducking；
- MP4 与字幕导出。

当前仓库没有正式视频渲染引擎。优先评估把固定版本 FFmpeg 作为受校验 Runtime Component；
引入前必须单独评审下载、校验、平台产物、许可证、编解码器、清理、诊断和降级。若采用
Remotion、云端合成服务或其他编辑 SDK，必须先完成许可证、账号依赖、离线能力和数据上传边界
评审，不能让合成服务变成本地工作台的启动前置条件。

## 状态所有者

| 状态                         | 唯一所有者                    | 持久化                         |
| ---------------------------- | ----------------------------- | ------------------------------ |
| 视频工程、场景顺序、品牌设置 | `MediaProjectService`         | 工作空间内版本化工程清单       |
| 工程资产、来源与哈希         | `MediaAssetService`           | 工作空间资产目录和 manifest    |
| 图片 Provider 调用           | 现有 `ImageGenerationService` | 任务和用量引用                 |
| 视频 Provider 调用           | `VideoGenerationService`      | 主进程任务账本                 |
| 合成与导出任务               | `MediaRenderService`          | 主进程任务账本与工作空间输出   |
| Provider 凭证                | `CredentialService`           | `userData` 本地凭证文件        |
| Tab 与编辑投影               | renderer tab/media store      | 可丢弃投影，不反向覆盖运行事实 |
| 用量统计                     | `UsageLedgerService`          | `userData/usage-events.jsonl`  |

工程必须绑定明确 `WorkspaceRef`。Tab 只是工程的可关闭视图；关闭 Tab、切换工作空间或窗口重建
不能取消后台任务，也不能让任务状态不可判断。

## 生命周期与权限

- 所有生成和渲染任务拥有稳定 ID、工作空间、工程 ID、场景 ID、Provider、当前步骤、开始/
  结束时间、进度、终态和脱敏错误；
- Provider 初始化失败只使对应 Provider 降级；
- 产生外部费用前显示确认卡；重新生成单个镜头也属于新的付费副作用；
- 导出本地文件不等于发布；发帖、上传或发送仍需最终人工确认；
- renderer 不直接请求 Provider、读取 Key、上传参考素材或下载生成结果；
- 发送到云 Provider 的提示词、图片和视频必须在付费确认卡中说明数据将离开本机；
- 任意任务失败不得阻断本地项目、Agent、浏览器、编辑器、Terminal、数据源和 Android。

## 失败与降级

| 场景                       | 行为                                                           |
| -------------------------- | -------------------------------------------------------------- |
| 没有视频 Provider          | 仍可完成分镜、素材搜索、静态动效视频和工程保存                 |
| Key 缺失、无效或余额不足   | Provider 单独不可用；显示原始分类，不影响其他本地能力          |
| 限流、内容审核或服务端失败 | 保留场景与请求事实，可修改提示词、延后重试或换素材             |
| 生成超时或应用重启         | 保留远端 task ID，重启后查询；无法查询时标记“状态未知”而非失败 |
| 下载 URL 过期              | 先尝试重新查询任务获取新地址；不把空文件当成功                 |
| 单个场景失败               | 其他场景和已完成资产保留，可单独重试或替换                     |
| 素材下载失败               | 保留来源记录，不创建损坏本地资产                               |
| 工程在生成期间修改         | 输出关联原场景 revision；不得覆盖更新后的场景选择              |
| 合成失败                   | 保留工程和中间资产，返回失败步骤与诊断                         |
| 用量账本失败               | 记录诊断，不丢弃已经交付的素材或视频                           |

## 建议交付顺序

### V0：一个真实国内云 Provider 的纵向闭环

用户可以从真实稿件生成分镜，添加本地/搜索/现有 AI 图片素材，对单个场景调用一个真实国内
云端视频 Provider，查看进度、选择结果、单独重试，最后导出带字幕、Logo 和音乐的 MP4。

### V1：旁白与品牌成片

增加云端 TTS 或用户旁白、字幕对齐、品牌模板、背景音乐 ducking、片头片尾和更可靠的预览，
让 30～45 秒视频具备实际发布质量。

### V2：多 Provider 与多版本

根据真实账号和质量证据增加第二个视频 Provider，支持同一分镜的横屏/竖屏版本、候选结果
对比、Provider 切换和费用汇总。

### V3：有限编辑增强

根据真实使用证据增加裁剪、关键帧、更多字幕样式和有限多轨能力。ComfyUI 只有在用户确实
需要本地或自定义工作流时再重新评估，不进入当前产品路线。

## 方案拷问

1. 如果云端模型生成都成功，字幕、音频、品牌和素材来源仍未闭环，能否称为宣发视频完成？
   不能。
2. 如果只接通云 API，用户仍需手工下载和拼接片段，能否称为产品里程碑？不能。
3. 如果只能重做整条视频，费用和等待时间是否可接受？不可接受，场景必须是最小重试单位。
4. 如果用户关闭 Tab 或重启 App，任务是否仍可判断？必须可以对账为运行、成功、失败、取消、
   状态未知或中断之一。
5. 如果素材能下载但来源无法追溯，是否允许导出？可以由用户显式承担自有素材责任；搜索
   Provider 素材不得丢失来源事实。
6. 如果云 Provider 离线或余额不足，是否失去整个工程？不能；工程、素材和合成仍可用，
   Provider 独立降级。
7. 如果合成引擎或云 Provider 需要额外许可证、账号或上传用户素材，是否已经向用户说明？
   未说明前不得作为默认依赖。

## 外部事实参考

- 火山引擎即梦视频 API、腾讯云混元/MPS、阿里云百炼万相、Vidu 和 MiniMax 海螺的异步任务；
- OpenAI Videos API、Runway API 与 Vertex AI Veo 作为后续国际 Provider 参考；
- Pexels 图片/视频搜索 API 及归因要求；
- FFmpeg、Remotion、OpenCut、Shotstack、Creatomate 等合成或编辑路线需在实现选型时重新核对
  当前版本、许可证、数据边界和维护状态。
