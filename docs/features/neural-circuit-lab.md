# 神经电路实验室产品设计

> 状态：讨论方案，尚未实现。2026-10-09。
> 用户已要求整理产品设计与目录架构，本轮不执行仿真、不接入硬件、不修改功能代码。

## 目标与当前边界

在 CCLink Studio 中提供可视化研究工作台，用于建立完整秀丽隐杆线虫神经系统模型，将其映射为忆阻器电路，开展仿真，逐步推进到芯片设计与可能的 FPGA 验证。

用户不要求围绕特定老师或论文开展访谈；老师身份及论文不作为开始产品设计的前提。实际计算仍需选择具有来源、适用范围和参数依据的模型，模型来源记录是复现实验资料，不是访谈门槛。

用户现在可以查看九页概念示意；还不能在 Studio 中运行该实验室的仿真、设计可制造芯片或进行板卡验证。完整线虫模型、求解器、忆阻器模型、工艺与板卡均未选定。

产品名称暂定“神经电路实验室”。产品功能进度目前仅为设计讨论；工程准备度为本设计文档、目录架构提案和可离线打开的页面示意。两者不构成功能交付。

## 用户端到端验收

首个用户能力的目标验收动作：

1. 在 Studio 打开本地工作空间，新建研究目录，选择忆阻器脉冲响应示例。
2. 在器件页查看模型及其适用条件；在电路页修改参数并保存。
3. 在实验页设置刺激、时长、步长和测量点，检查实际仿真环境。
4. 运行真实求解器，查看运行状态、节点波形和原始输出。
5. 修改一个参数并生成第二次运行，对比相同物理量、单位和时间范围。
6. 保存、关闭并重新打开，找到两次记录，按固定输入重跑。
7. 模拟工具缺失、计算失败或主动停止，看到明确原因和部分结果标识。

必须记录真实 Studio 验收结果；目前以上步骤均未执行。样例波形、前端动画、mock 或自动测试不替代真实仿真。

长期目标验收：导入选定版本的完整神经系统，检查结构覆盖及参数缺口；在固定刺激下运行参考模型与映射电路，对比响应；有参考证据的功能才可宣称复现。运动或退避等行为需要身体、肌肉与环境模型，神经活动回放不能替代行为验收。

## 仿真层级与证据

| 层级 | 功能 | 所需条件 | 可作出的结论 |
| --- | --- | --- | --- |
| 器件物理 | 材料、结构与阻变机制计算 | 物理方程、几何、边界、参数、物理求解器 | 特定模型下的器件响应 |
| 电路行为 | 忆阻器与外围电路的时间响应 | 紧凑模型、网表、激励、求解设置 | 电路模型在适用条件下的行为 |
| 神经网络 | 神经元动力学及信号传播 | 连接数据、连接类型、方程、参数 | 指定神经系统模型的响应 |
| 芯片物理设计 | 布局、互连、规则检查与寄生分析 | 工艺 PDK、器件工艺支持、物理设计工具 | 相应物理检查结果；不能仅据电路仿真声明可制造 |
| FPGA 数字验证 | 数字模型或控制逻辑的板上运行 | RTL、工具链、板卡、参考结果 | 数字实现正确性、时序和资源使用 |
| 真实器件测试 | 控制、采样与真实电路比较 | 器件、模拟接口、仪器、限流及操作授权 | 本次真实电路的测量结果 |

忆阻器承担突触、神经元或两者尚待选择；化学突触与电突触分别建模，不自动统一为相同电阻连接。结构完整、动态可运行和生物功能相符分别验收。

## 信息架构与页面

在现有 Studio 工作台中增加领域入口，复用工作空间、文件树、Workbench Tab、Agent Panel 与 Terminal。九页是领域内视图，不建立第二套全局导航或 Tab 系统。示意中“新建实验”绑定当前工作空间；“导入工作空间”应使用 Studio 既有打开入口。

| 页面 | 用户目的 | 主要功能与对象 | 空态和失败态 | 首轮范围 |
| --- | --- | --- | --- | --- |
| 实验室首页 | 继续研究或从示例开始 | 当前工作空间研究目录、近期实验、环境状态、新建和打开 | 没有研究目录时提供示例；工具缺失可继续编辑 | 首轮 |
| 神经网络 | 查看结构并定位局部回路 | 数据导入、搜索、筛选、连接类型、属性、刺激点、跳转电路 | 来源或参数缺失可见；不得自动补成已验证数据 | 首轮只读浏览与关联；动态全系统后续 |
| 器件与模型 | 确认模型并测试器件 | 模型库、格式、来源、授权、参数、单位、适用范围、单器件测试 | 不支持的模型格式拒绝运行，保留原文件 | 首轮受限模型范围 |
| 电路设计 | 编辑可计算的电路 | 元件库、连线、撤销、属性、层级子电路、检查、映射关联 | 悬空、模型缺失、单位错误定位到对象 | 首轮示例电路编辑；编辑器复杂度待验证 |
| 实验配置 | 定义可重跑测试 | 刺激、初始条件、时长、步长、测量点、参考与判据 | 输入不完整阻止运行；未保存改动需明确是否采用 | 首轮固定刺激与时间响应；扫描后续 |
| 仿真与结果 | 观察并判断结果 | 运行和停止、波形、信号选择、对比、导出、日志、网络回放 | 失败、停止和部分输出分别标识；历史输入与当前修改区分 | 首轮波形与两次对比；网络同步回放后续 |
| 芯片设计 | 从电路走向物理实现 | 工艺配置、版图、面积功耗、规则检查、寄生提取、版图后仿真 | 没有工具或 PDK 显示未接入，不能给虚构指标 | 后续规划 |
| FPGA 与硬件 | 验证数字实现或真实电路 | 工具链、板卡、工程、综合、烧录、采样、参考比较 | 未连接、构建失败、断连与采样缺失明确显示 | 后续规划 |
| 实验记录 | 追溯和复现 | 输入快照、环境版本、输出、日志、备注、重跑 | 来源缺失、环境不兼容、重启中断清晰可见 | 首轮 |

## 页面布局

- 通用布局：左侧领域导航与文件；中间编辑或结果；右侧选中对象属性；底部诊断和运行。属性面板按需要出现，不强制占用结果空间。
- 首页：继续研究、示例、近期实验和环境；不展示未经计算的“研究进度百分比”。
- 网络页：总览与局部回路切换；完整图支持层次、过滤与聚合，禁止将所有连接挤成不可读图片。
- 器件页：模型列表、单器件输出和参数；修改模型与执行测试分开。
- 电路页：符号画布、元件库、属性及检查。几何布局与电气拓扑区分，移动符号不改变连接语义。
- 实验页：输入、计算条件、观察与比较、运行前检查四区。
- 结果页：波形为主要视图，网络回放与证据为辅助；时间游标和选中对象关联。同类物理量比较，不能混用神经活动代理量和电压。
- 芯片页：物理预览、设计条件、验证报告；概念分区与真实版图区分。
- FPGA 页：设备、验证模式、工程执行和采集结果；每次烧录明确目标与配置文件。
- 记录页：记录列表与详情，绑定当次输入；重跑产生新记录，原输出不覆盖。

## 贯穿功能与权限

保存、关闭脏编辑确认、快捷键、命令面板和右键统一引用现有 command/contribution。模型和实验文件支持版本、原子写与冲突提示。图形选中、时间游标和布局偏好属于 UI；它们不能写运行成功状态。

Agent 可解释日志、准备实验和提出模型修改，必须经过同一领域命令与权限入口，不成为第二求解器或第二运行状态所有者。AI 输出为候选，不能作为验证证据。

普通本地运行绑定用户选定的模型、工具和输出目录。执行第三方模型包含真实程序执行风险；模型导入不自动执行，任意脚本与任意 executable 不作为首轮默认功能。烧录、向真实器件施压、删除原始测量数据分别需要明确操作范围；本轮未授权这些操作。

## 最小闭环与扩展顺序

1. 固定一个求解器与可用忆阻器模型，验证真实计算、取消、结果读取和重跑，随后交付上述用户闭环。
2. 加入完整神经网络浏览、来源检查、选定回路的参考模型与电路映射对比；首轮结构浏览不等于此闭环完成。
3. 扩展为完整网络动态模型，测试规模、数值稳定性及参考响应。
4. 在具体工艺和硬件条件成立后，分别推进芯片物理设计与 FPGA 验证。

每一阶段都以用户操作和真实结果验收；Schema、适配器、构建和测试属于工程准备度。单项前置超过 60 分钟或同一阻塞失败两次应止损，不持续扩张基础设施。

## 方案拷问与待定事项

最容易失败的是完成漂亮画布，却没有真实可复现计算。下一步应验证求解器和模型能否运行，再限定编辑器支持范围；当前没有选定软件、许可条件或板卡，不能给出确定工具链与性能承诺。

须分别回答：完整网络采用什么生物版本？忆阻器实现哪个功能？有什么参考数据支持误差判据？当前工具能否承担目标规模？是否具备制造忆阻器的工艺支持？FPGA 是数字替身还是测量控制器？这些决定实际能力，但不阻止先完成产品设计。

参考背景：[OpenWorm 神经系统模型](https://openworm.org/science.html)、[解剖连接与信号传播研究](https://www.nature.com/articles/s41586-023-06683-4)、[Cadence 定制芯片工具功能](https://www.cadence.com/en_US/home/tools/custom-ic-analog-rf-design.html)、[Vivado 工具功能](https://www.amd.com/en/products/software/adaptive-socs-and-fpgas/vivado.html)。这些是候选背景，不代表已选用对应模型或工具。
