# 神经电路实验室产品设计（已取代）

> 状态：Superseded。2026-10-10。

原方案把线虫神经研究、忆阻器电路、芯片设计和 FPGA/硬件串成一个产品，页面数量和工程对象超过了可验证的用户闭环，也混淆了“结构完整”“动态可运行”和“功能复现”。该方向不再作为产品事实源。

当前方案：

- [仿生大脑产品设计](bionic-brain.md)：独立、本地的线虫神经模型浏览、刺激、仿真、回放、比较与复现产品域。
- [仿生大脑项目与运行架构](../architecture/bionic-brain.md)：目录、对象关系、状态所有者、引擎边界和失败降级。
- [聚焦首个纵向闭环的页面示意](../design/bionic-brain/pages.html)。

芯片、忆阻器、RTL、FPGA、版图和 EDA 不属于仿生大脑。未来只允许通过 Hardware Target Specification 单向导出大脑侧计算要求与参考结果。
