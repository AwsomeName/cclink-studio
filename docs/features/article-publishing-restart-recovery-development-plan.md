# 文章发布中断恢复开发方案

状态：已按单一事实状态方案落地，真实 CSDN 验收待执行
日期：2026-09-01

## 验收动作

1. 新建一条带本地图片的 CSDN 发布任务，执行到草稿已保存。
2. 在正文填写、图片上传、保存草稿、发布点击后的不同时间点强制退出 Studio。
3. 重启后点击“从中断处继续”。
4. 观察 Studio 进入原账号草稿箱、打开原 draftId，而不是使用失效旧 URL 或新建文章。
5. 已完成步骤保持完成；只处理未完成或结果未知步骤。
6. 对结果未知图片，用户在可见网页中选择“有这张图”或“没有，重新上传”，不填写 URL。
7. 对发布结果未知，Studio只查文章管理页，不再次点击发布。

## 已实现

- `ArticlePublishingState` 删除全部文章、图片、检查点、快照和动作指纹字段；
- 源文件变化判断改为路径、大小、修改时间；图片身份改为任务内稳定资产 ID；
- CSDN adapter 不下载图片、不计算正文或图片指纹；
- 草稿恢复只核验真实账号、draftId、标题和保存状态；
- 写入许可只绑定 recovery operation、执行代次和当前 Browser/CDP Runtime；
- 写后回读只确认同账号、同草稿、已保存，不续签内容快照；
- 副作用账本使用结构化 key 和一次性状态，不使用动作指纹；
- 已确认上传的图片不会因 CDN URL 变化而降级；
- 结果未知图片提供人工“存在/缺失”按钮，不要求用户输入地址；
- 发布结果未知按账号和标题查公开文章，不假设公开 ID 等于草稿 ID；
- Schema 升至 v7；旧文章发布事务从主文件、备份和旧恢复日志删除，不迁移；
- recovery lease 在找草稿前取得，核验后原子转交 BrowserTask。

## 状态所有者和权限

- `WebAffairService` 是文章任务唯一持久状态所有者；
- `ArticlePublishingService` 负责恢复编排和 Runtime 生命周期；
- `CsdnPublishingAdapter` 只读取当前网页事实和受支持 selector；
- `BrowserTaskRuntime` 拥有账号级普通租约与 recovery lease；
- renderer 只能通过有界 IPC 发起“继续、终止、图片人工确认”，不能直接改状态；
- Agent 未拿到当前 Runtime 写入许可前不能修改网页。

## 仍需真实平台验收

- CSDN 草稿箱在分页、搜索、空列表和多个同名标题下的真实 DOM；
- CSDN 可稳定读取的账号标识；
- 草稿保存状态在不同编辑器版本中的真实提示；
- 图片上传后平台 URL 的读回时机；
- 文章管理页标题文本与公开页账号的真实可读性；
- 人工确认图片后继续上传或跳过的完整 UI 路径。

在这些真人步骤通过前，只能声明工程门禁通过，不能声明真实 CSDN 产品闭环完成。

## 自动验证

- 类型与 IPC schema 拒绝旧内容指纹字段；
- v1-v6 文章事务被删除，v7 新任务可正常持久化；
- 新任务重启后保留，旧主文件、备份和恢复日志不再恢复文章任务；
- 草稿恢复必须账号、draftId、标题、保存状态一致；
- recovery lease 冲突和 Runtime 身份变化时 fail closed；
- 未决上传、保存、发布不能直接重放；
- 图片人工“存在/缺失”会形成可恢复的明确状态；
- 公开文章 ID 与草稿 ID 不同时仍可按账号和标题收敛结果。
