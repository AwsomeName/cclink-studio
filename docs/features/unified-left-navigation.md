# 左侧导航统一收放

2026-11-05 用户确认：左上角同时收起文字导航与内容栏，只保留图标；再次展开恢复文件树位置和栏宽，右侧 Agent 保持不变。

## 用户验收

1. 在本地工作空间展开一层目录，将文件树向下滚动，拖动内容栏到所需宽度，保持右侧 Agent 可见。
2. 点击左上角“收起左侧栏”：导航变为 48px 图标栏，内容栏隐藏，中央工作区得到释放的宽度；Agent 的模式、实际宽度与位置不变。
3. 再次点击：恢复 140px 文字导航及原内容栏宽度，目录仍展开，滚动位置不变。重复收放仍应成立。
4. 收起后点击“文件”图标：恢复上述两栏；其他能力沿用原入口语义。悬停能看名称，键盘能访问所有图标及设置，隐藏内容栏不能获得焦点。
5. 在窄窗口重复收放：已经临时压缩的 Agent 不因左侧隐藏而自动变宽；窗口重新放大时仍恢复保存的宽度目标。
6. 在 A、B 两个工作空间分别展开与收起，往返并重启：复用各自保存的显隐和宽度，不互相覆盖。
7. 打开内嵌网页执行同样动作：原生 View 对齐中央 pane，不盖住导航、Tab 和工具栏，page zoom 与 visual scale 不回归 30%。

## 边界与实现

- `useUIStore.sidebarVisible` 是唯一显隐事实；Activity Bar 仅投影文字或图标样式。继续复用原有命令、快捷键、右键菜单和工作空间持久化，不新增显隐开关、IPC、权限或登录前置。
- 展开宽 140px、收起宽 48px；图标、顺序、分组、选中状态保持。收起时分组标题改为分隔线，任务计数移为图标角标，设置继续固定在底部。
- Sidebar 收起期间保持挂载，`inert` 阻断隐藏内容获得键盘焦点；目录展开状态与滚动容器不重建。只收放不写入新的栏宽。
- `usePanelLayout` 只保留当前工作空间内可丢弃的布局呈现，收放时保留 Agent 的实际宽度；拖拽预览不进入保留值。工作空间、窗口宽度或 Agent 模式变化时重新按原预算计算，显式调宽仍有效。
- 窄窗口中，如果先在收起状态将 Agent 调宽，再展开左侧，优先满足 Agent 不变；内容栏可临时压缩到既有 160px 下限，中央区可能小于通常的 320px。保存的宽度目标不变，放大窗口后恢复。通常展开状态下的窗口缩放预算不变。
- 无新增服务或监听生命周期。布局故障沿用现有区域错误边界；本地能力不依赖远程服务，原生网页 bounds 和缩放仍由 BrowserManager 独占。
