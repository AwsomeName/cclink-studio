## 用户验收动作

用户将包含自动安装能力的正式签名 arm64 Studio 安装到本机可写目录，打开工作空间与
文档 → 检查并下载新版 → 点击“安装并重启” → 处理阻塞事项 → 确认安装 →
Studio 正常退出、替换应用并重新打开 → 核对版本、工作空间、标签和文档。

受影响的 v0.1.105 已有安装程序，但安装前会话保存失败，仍需手工安装一次首个修复版。
之后仍需两轮正式版本的真人验收；实验程序代为生成启动回执不能替代新版内置回执验收。

## 用户功能进度

- 正式版已支持公开稳定/测试 Release 的检查、受控后台下载、取消和重试。
- 已支持私有缓存、长度与 SHA-256 校验、重启恢复和可信 DMG 手工安装。
- v0.1.105 已公开安装确认、工作现场检查、保存、替换与重新启动链路。
- 真实 v0.1.105 → v0.1.106 在工作现场保存阶段失败；公开用户还不能依赖该入口完成自动
  替换。最小修复已完成工程实现；首个修复版及其后两轮应用内升级验收待执行。

## 工程准备度与边界

- UpdateService 仍是唯一产品状态所有者，不引入 autoUpdater 或 electron-updater。
- 使用 Manifest v3 的唯一 arm64 DMG，不新增 ZIP、第二 Provider 或第二缓存。
- MacDmgVerifier 在只读挂载内检查候选，再复制到当前应用目录的私有同卷暂存区；
  复制后再次核对公证、Team ID、Bundle ID、版本、签名和架构。
- MacUpdateInstaller 只消费内部 verified handle；renderer 不提供 URL、路径、
  Team ID、父进程 PID 或替换参数。
- 原生 Helper 进入 Resources，由正式 Release 的 Developer ID 签名与公证覆盖。
  Release 门禁确认该程序签名和 arm64 架构；开发 ad-hoc 包不开放安装。
- Helper 等旧进程自行退出，不强杀旧版；同卷原子交换保持应用路径始终存在。
  独立监督进程处理 worker 异常；新版未给出启动回执时恢复并重开旧版。
- 事务文件权限为 0600，事务/暂存目录为 0700；不申请提权、不使用系统凭证存储。
- 旧应用备份保留在本次暂存区，尚未实现自动轮换清理；事务不能被下载缓存恢复删除。
  应用回滚不等于撤销用户数据格式迁移，后续数据迁移必须保持旧版兼容性。

## 工作现场保护

复用可信 renderer 的工作空间 flush 握手；检查请求不保存、不退出、不取消任务。

1. prepareInstall 汇总未保存标签、活动 Agent、终端、浏览器任务/下载、
   定时任务、远程请求/上传及媒体生成/渲染事实；辅助窗口也需要先保存并关闭。
2. 阻塞事项展示原因，不签发令牌。闲置 shell 也要求用户先关闭，
   不猜测其中的前台命令是否可以中断。
3. 没有阻塞时签发绑定候选 operationId、60 秒过期的一次性令牌；取消清空 UI 确认。
4. 确认后冻结交互。暂存前、暂存后和退出前重新检查；Agent 复用现有配置变更保护，
   定时任务暂停新调度，失败时恢复，不取消已经运行的任务。
5. renderer 写队列和主进程领域存储 flush 成功后，才提交事务并调用现有退出生命周期。
   检查、保存、权限或启动失败不退出，保留手工安装入口。
6. 新版完成 runtime bootstrap，并收到实际 renderer 持久化确认后才写回执；
   Helper 核对 nonce、版本和自己启动的 PID，不能以启动进程冒充工作台启动成功。

## 剩余验收

- 原生闸门：两个公开签名、公证 App 的隔离副本，真实交换/启动、候选损坏、取消、
  无写权限、worker 异常与无启动回执回滚；命令与结果写入 ops 验收记录。
- 正式基线：官方签名 Helper 随 App 一起公证，应用内显示安装入口；ad-hoc、DMG
  挂载、App Translocation 或无写权限时安全拒绝并保留兜底。
- 用户闭环：两轮正式版本应用内下载→确认→自动重启，核对版本及原工作空间恢复。
- 故障闭环：未保存内容、活动任务、flush 失败及过期令牌不退出；
  启动失败后旧版窗口可用并显示失败信息。

## 止损与交付纪律

同一阻塞失败两次或单项前置超过 60 分钟时停止扩大验证范围，先报告阻塞与保留手工
安装的替代路径。原生实验不过门禁不启用正式入口；两轮正式验收未完成不宣称产品闭环。
正式发布仍只使用 pnpm release -- --patch --yes，复用精确 main SHA 的绿色远端 CI。
