# 我的空间 · 科技日报（Argus techdaily 复刻方案）

> 日期：2026-11-25。状态：方案 v2，效果图待用户确认，未实现。
> 定位（用户确认）：**我的空间的标准功能**，任何用户配好搜索服务（DeepSeek Key 或自建 SearXNG）即可开启。
> 复刻对象：Argus techdaily。依据本机留存的 Argus 代码（2026-10，`src/argus/techdaily/*`、`stocknews/urlnorm.py`）
> 和用户给出的 `daily.md` 章节说明；服务器上的完整规格书本机读不到，实现前对照补齐。
> 效果图与架构图：[v2/README.md](../design/techdaily-2026-11-25/v2/README.md)。

## 1. 用户验收（先于工程任务）

1. **项目设置 · 我的空间 · 科技日报**：选搜索服务（DeepSeek 沿用联网搜索的 Key；或填 SearXNG 地址并“测试连接”），开启。
2. **侧栏点“科技日报”**：下方日历切换为科技日报日历，有日报的日子带圆点；点日期，中间用与日记相同的 Markdown 编辑器显示当天 `科技日报/2026/11/1125.md`。
3. 点“重新生成”或等到点：执行详情显示 10 步随真实执行变化；完成后编辑器直接显示当天日报。
4. 日报包含：头条解读、模型能力榜（7 个榜单）、分领域精选（9 个领域 + 热点补充）、开源热点、论文前沿、今日趋势、数据口径。
5. 同一事件不连续几天重复出现；后续进展标“⬆ 前情：X 月 X 日已报道”。
6. 06:10 时 Studio 没开，打开后补生成当天的；过去没生成的日子显示“这天没有科技日报”，不补。

**首版完成**以第 1–6 项在真实 Studio、真实 Key 或真实 SearXNG 下连续 3 天通过为准。

## 3. 日报章节（照 Argus `render_markdown`）

```markdown
# 科技日报 | 11月25日

## {头条标题} ← 不带“今日头条”字样，渲染层再剥一次

{3–5 句深度解读}
[原文](url)（N 个来源）

## 模型能力 ← 固定栏目，不依赖当天是否有模型新闻；榜单为空才不出现

### 代码 / Agent / 多模态 / 图片生成 / 视频生成 / ASR / 具身智能

| # | 模型 | 得分/口径 | 备注 | ← 🆕 行 = 观察区（“观察中”，注明展示截止日）
数据源：{口径} · {站点}（YYYY-MM-DD 抓取）

## {领域名} ← 按成稿输出的 sections 顺序；头条条目在分栏中去重

**{标题}**
_⬆ 前情：YYYY-MM-DD 已报道本事件，今日为后续进展_ ← 仅非首报
{2 句摘要}

> 点评：{1 句}
> [原文](url)（N 个来源） · YYYY-MM-DD 或“日期未知”

## 开源热点 / ## 论文前沿 ← 速览：- **repo 或中文译题** · 一句话说明 [→](url)

---

## **今日趋势**：{一句话}

_数据口径：原始 X → 去重 X → 入库新增 X → 候选 X → 精选 X（run YYYYMMDD-HHMMSS）_
```

领域（采集顺序与标题映射，`设置.yaml` 可改）：模型能力、模型架构、AI 芯片与显卡、芯片制造、科技巨头动态、具身智能、机器人、AR/VR、生物×AI；
扩展展示域：热点补充、开源热点、论文前沿。

## 4. 搜索服务

| 提供方                | 首版 | 规则                                                                         |
| --------------------- | ---- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DeepSeek              | ✓    | `WebSearchService`，来源记“科技日报”；每次 ≤ 15 条；结果 `date` 作第二级日期 |
| SearXNG 远程服务      | ✓    | `GET {地址}/search?q=&format=json&categories=news&language=zh-CN             | en`；**绝不传 `time_range`**（实测清空结果）；只采用白名单引擎（默认 bing、bing news、duckduckgo news）的结果（`engines` 参数不可靠）；同主机间隔 3.5 秒、429 指数退避；`publishedDate` 作第二级日期 |
| Brave / Tavily / 博查 | 后续 | 同一接口，按需接入                                                           |

- SearXNG 不提供网页读取：成稿用搜索摘要；若同时配了 DeepSeek，可勾选“用 DeepSeek 读取原文”。
- “测试连接”：搜一次 `AI chip`，返回条数、带日期比例、实际引擎分布、耗时；不保存结果。
- 凭证（Basic 认证）进凭证文件，不进 `设置.yaml`、日志或界面回显。

## 5. 每日流程（10 步，对应执行详情）

| #   | 步骤               | 执行者                            | 完成证据                                      | 失败                                |
| --- | ------------------ | --------------------------------- | --------------------------------------------- | ----------------------------------- |
| 1   | 检查               | Studio                            | 搜索服务、AI、今日余量、当天是否已有日报      | 停，说明去哪里修                    |
| 2   | 读取               | Studio                            | 设置.yaml、近 5 天事件登记、榜单.json         | 设置损坏：停并给出行号              |
| 3   | 按领域搜索并过滤   | Studio → 搜索服务                 | 各领域：请求数、原始、L0 各门丢弃数、无日期数 | 单词重试 1 次；领域全空标“可能限流” |
| 4   | 前沿信号与热点补采 | Studio → HN/GitHub/arXiv，AI 规划 | 信号条数、补搜词（≤ 3）、补采条数             | 跳过，不阻塞                        |
| 5   | 合并入库           | Studio                            | 跨域合并数、候选新增/更新                     | —                                   |
| 6   | 整理候选           | Studio                            | 候选数（≤ 300）、已报道标记数                 | < 8 条：写“候选不足”短报            |
| 7   | AI 精选 5–10 条    | AI（纯文本）+ 代码校验            | 入选数、归组数、复用 uid 数                   | JSON 两次失败：停，候选保留         |
| 8   | 读取原文并成稿     | 搜索服务读取 → AI                 | 读取页数、成稿条数                            | 读取失败用摘要；成稿失败停          |
| 9   | 更新模型能力榜     | Studio → 源站，AI 维护            | 各榜源站行数、观察区变化                      | 源站失败：该榜只按新闻维护          |
| 10  | 保存并核对         | Studio                            | 写入文件路径、剔除条数                        | 剩余 < 5 条仍保存并标出             |

前沿源（照 Argus `trending.py`，全部免费公开 API）：
HN topstories 前 25 条且分数 ≥ 50；GitHub 近 14 天按 topic 创建、≥ 80 星，取前 3 进速览；arXiv `cat:cs.AI OR cat:cs.RO OR cat:q-bio.NC` 最新 20 篇，取前 3。

## 6. 去除与去重（逐层）

架构图与漏斗图见效果稿 `v2/diagrams.html` ④。

### L0 过滤门（每条结果，按顺序）

1. 网址以 http(s) 开头、标题非空。
2. 域名黑名单：Argus `DOMAIN_DENYLIST` 全量（百科、词典、旅游、课程、AI 产品官网与下载页、github.com、仿冒域名），设置里可追加。
3. SearXNG：引擎白名单。
4. 排除词（标题）。
5. 两级时效门：网址日期（11 种形态，顺序敏感：`/2026/07-10/`、`/2026-0903/`、`/2026/0903/`、`doc-YYYYMMDD`、东财 `/a/`、证券星 `/RB`、fx678 `/content/`、`/tYYYYMMDD_`、腾讯 `YYYYMMDD[A-Z]`、查询参数 `pub_date|ptime|…`、裸 `YYYYMMDD`）→ 结果日期。早于 N 天（默认 3）丢弃；晚于明天视为误匹配。都没有：**保留并标无日期**（设置可改为丢弃）。
6. 标题护栏：护栏词 = 搜索词去停用词 + 领域“标题须含”词。标题命中 → 通过，但“无日期且只命中品牌词”拦；标题未命中、摘要前 300 字命中 → 仅有日期时通过。
   停用词：中 `发布 动态 新闻 资讯 落地 应用 公司 行业 集团 最新 ai`；英 `news release launch announcement update latest ai`。品牌词：Argus `_BRAND_TOKENS` ∪ 领域“标题须含”词。

### L1 网址合并

规范化：小写主机、去默认端口、去 fragment、去跟踪参数（`utm_*` `spm` `from` `share` `fr` `src` `source` `ref` `chk(s)` `tt_from` `igshid` `_t` `timestamp` `pos` `refer`）、参数排序、去尾斜杠。
键 = 规范化网址 SHA-256 前 16 位；原始网址保留。
L1a 领域内、L1b 跨领域（先到领域保留）：追加搜索词与引擎、补齐日期，不新增。

### L2 候选库

`candidates.jsonl`（本机，14 天）。同键再次命中只更新最近抓取日与搜索词；首见日不变。
取候选：最近抓取日 ≥ 昨天，发布日期降序、无日期殿后，≤ 300；曾入选的标“⚠ 已报道过”。

### L3 同事件归组（AI，代码校验）

`rep` + `also[]`；编号越界、重复、已被用 → 剔除；来源数 = 1 + also 数。

### L4 跨天事件去重

- 事件登记 `科技日报/事件.json`（随同步，30 天）：`uid`、事件名、首报日、最近报道日、报道日期、网址、重要度。
- 精选提示给近 5 天全部事件（最近报道日降序 + uid 次序，≤ 120）。
- 已报道默认不选；新进展最多 1 条、不做头条、标题直陈新进展、理由以“新进展：”开头。
- AI 自造 uid 丢弃 → `similarEventName` 兜底 → 都不中才新建 uid（`event:tech:` + MD5(事件名) 前 16 位）。
- `similarEventName`：型号数字冲突、区分性英文词互斥 → 否决；实体（首中文段前 2 字或首个非通用英文词）+ 动作组（发布/推出/官宣、开售/发售/上市、量产/投产、上线、开源、融资/注资、交付、扩产、成立、召开/举行）+ 对象（内容二元组交集 ≥ 2，或共享区分性英文词且有中文交集，或共享数字型号）全中才判同。宁可漏合。

## 7. AI 调用（每天 ≤ 4 次自动 + 手动重试，上限 8）

| 调用     | 输入                                                                   | 输出（Zod 校验）                                                              |
| -------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 热点规划 | HN/GitHub/arXiv 信号 ≤ 30、已采集标题 ≤ 250                            | `{queries ≤ 3, reason}`；精短 2–4 个名词，禁止泛化词                          |
| 精选     | 候选 `[i] (领域｜日期)⚠ 标题｜摘要 120 字`、事件登记、口味与黑名单品牌 | `items[{rep, also, reason, importance, event_uid, event_name}]`、`trend_hint` |
| 成稿     | 槽位 `领域#序号`、标题、原文或摘要 400 字、来源数、入选理由；速览条目  | `headline{slot,title,analysis}`、`sections[]`、`quick[]`、`trend`             |
| 榜单维护 | 当前榜单 JSON、近 7 天模型评测相关候选                                 | 完整榜单 JSON                                                                 |

- 纯文本 Agent（`disableBuiltinTools` + 空 `allowedTools`），Codex 优先、Claude Code 兜底（ADR 0023）。
- 提示词移植 Argus 的 `DYNAMIC / SELECT / RENDER / LEADERBOARD_SYSTEM_PROMPT`。
- JSON 容错：剥围栏 → 解析 → 修复中文夹英文引号 → 截取最外层花括号；失败带修正提示重试 1 次。
- 网址、日期、来源数、事件首报日由代码回填，AI 输出的网址不采用。

## 8. 模型能力榜

- 状态文件 `科技日报/榜单.json`（随同步、可手改）：`tasks{代码, Agent, 多模态, 图片生成, 视频生成, ASR, 具身智能}`，每榜 `rows ≤ 5`、`new_entries[{until}]`、`_source{name, site, fetched_at}`。
- 源站（主进程直接 HTTPS 读取公开页面，礼貌 UA，间隔 1.2 秒，每天 ≤ 6 页，不经搜索服务、不计费）：
  llm-stats.com 主榜（Agent）、`/benchmarks/swe-bench-verified`（代码）、`/benchmarks/mmmu-pro`（多模态）；
  artificialanalysis.ai 文生图、文生视频（Elo）、语音转写（WER，升序）。具身智能无可读榜单，只按新闻维护。
- 规则（照 Argus）：源站分数为准，AI 不得改回空或删除；无评测证据不动排名；当天新模型进观察区、次日到期；旗舰系列到期默认升入，非旗舰需进前 5 证据；同家族去重。
- 源站解析失败：该榜缺席或沿用旧值，日报注明抓取日期。

## 9. 调度与“每天最多一次”

- 定时任务服务是唯一调度者；日报是内置流程任务，执行交给 `TechDailyService`。**实现前提交 ADR 0027**（扩展“定时任务 = 指令 + Agent”）。
- 运行记录 `runs/<日期>/run.json`：`running → completed | empty | failed | interrupted`。
- 自动触发前：当天 `completed/empty` 或 `running` → 不触发；进程内锁防并发；手动“重新生成”需确认并覆盖当天文件。
- 日期在开始时确定，跨午夜仍算开始那天，不补前一天。
- 补生成：开启时，Studio 启动后若已过设定时间且当天无日报 → 30 秒后排队。
- 多设备：随 Git 来的共享定义默认不启用。

## 11. 费用

- DeepSeek：约 36 次搜索 + ≤ 3 次补搜 + ≤ 10 页读取 ≈ 49 次/天 ≈ $0.04/天、约 $1.1/月。
- SearXNG：搜索免费；读取原文可选 DeepSeek。
- 前沿源与榜单源站：免费公开页面。AI：本机 Codex / Claude Code。
- 日报自有每日上限默认 80 次 DeepSeek 调用，同时计入联网搜索每月总上限。

## 13. 测试清单

- 网址规范化、11 种网址日期、未来日期拒绝、长 id 不误匹配。
- 时效门两级顺序；无日期保留/丢弃开关。
- 护栏：话题型查询摘要命中且有日期 → 过；“DeepSeek | Into the Unknown”无日期只沾品牌 → 拦；“DeepSeek 发布 V4.1 Flash” → 过。
- L1a/L1b/L2 合并：首见日不变、日期补齐、搜索词追加。
- 事件名相似：启元开售 vs 启元正式发售 → 同；睿芯 D35 量产 vs 睿芯宣布 D35 数据流芯片量产 → 同；Sonnet 5.5 vs Opus 5.5 → 不同；阿里千问发布同传大模型 vs 阿里研发 QwenBook 平板 → 不同。
- 精选校验、JSON 容错、榜单“真实分数不可被改回空”。
- SearXNG：不传 time_range、引擎白名单、429 退避、Basic 凭证不落日志。
- 调度：当天已完成不重复、跨午夜不补、中断重来、补生成开关。
- 真实 Electron：项目设置开启与测试连接、侧栏日历切换、点日期显示 Markdown、生成中 10 步、无日报日子。

## 14. 拷问

- **把科技日报配置塞进项目设置会不会太长？** 是长。段落可折叠，默认只展开“搜索服务”和“什么时候生成”；词表细节可直接编辑 `设置.yaml`。
- **日历同时显示日记和日报会不会混？** 不混：侧栏切到哪个，日历就显示哪个的圆点和计数。
- **抓 llm-stats / AA 的 HTML 会不会坏？** 会，Argus 已踩过（arena 页客户端渲染抓不到、mmmu 页停更）。解析失败只让该榜沿用旧值并标抓取日期，不阻塞日报；解析器有快照测试。
- **SearXNG 凭证是否安全？** 存凭证文件（权限收紧），不进同步目录、日志或 IPC 返回；不用系统钥匙串。
