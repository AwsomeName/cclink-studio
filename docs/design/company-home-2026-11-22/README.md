## 从首页到市场与试戴跟进

- “去跟进”“去审阅”“去筛选”“去取材”打开“市场与用户”标签，并定位到对应列（效果稿内嵌市场页面）。
- 账号需要重新登录时，“打开账号页面”打开该账号的浏览器环境（工具栏显示“账号 · 星河眼镜”），在原页面扫码登录后点“交还 Agent 并继续”，发布从停下的步骤继续，首页待办随之消失。
- “管理账号”打开设置里现有的“网站与账号”：本机全局目录、登录状态、确认登录、运营矩阵和凭证边界说明，不新建账号界面。
