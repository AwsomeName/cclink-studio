# Owner 联网取证 · 设计稿

2026-11-27 方案稿。开发版已实现公开网页通道（搜索、读取、快照、计数、上限追加、引用核对、Owner 设置里的默认上限），尚未真人验收。[打开可交互设计稿](mockup.html)。示例事务："对比 Ibex 和 PicoRV32 的社区评价和维护状况"。

## 一句话

Owner 调研可以查公开网页了：执行会话说要搜什么、读哪个网址，Studio 用已有的 DeepSeek 联网服务去搜、去读，把每一页存成快照放进 `资料/网页/`。报告里引用网页原文，交付前按快照逐条核对，和 GitHub、本地引用同一套规则。模型自带的搜索只算线索，不能直接当引用。

## 为什么不用模型自带的搜索

- 覆盖不够：Codex、Claude Code 自带搜索的来源和深度不受 Studio 控制，也没法按事务加上限。
- 核对不了：搜索在模型那一侧完成，Studio 拿不到原文，报告里的网页引用无法和原文比对。
- 换运行时会变：不同运行时的搜索能力不同，同一件事务换个模型结果就不一样。

所以联网取证由 Studio 执行：查询、读取、存档、计数、核对都在 Studio 这边，任何运行时用的都是同一个通道。

## 用户看到什么

| 阶段 | 看到的内容 |
| --- | --- |
| Owner 设置 | 新增"取证通道"：公开网页（DeepSeek）的状态、本月用量和单价；每件事务的默认联网上限（默认 20 次）；"模型自带搜索只算线索"的说明。GitHub 深度读取、论文、内嵌浏览器、本地数据源列为后续 |
| 约定与授权 | "直接做"里多一项"查公开网页 · 最多 20 次"，并写明搜索词和网址会发给 DeepSeek、预计最多花费多少。计划里每一步写明能不能联网 |
| 运行中 | "取证记录"列出每次搜索的搜索词和结果数、每次抓取的网页（标题、域名、读取时间、字数、哈希、状态），顶部显示"已用 N / 20 次" |
| 用到上限 | 右侧事务官问你"再给 10 次？"。60 秒无回应就停止联网，用已有资料继续，报告里注明"联网次数已用完" |
| 打开快照 | 中间标签打开网页快照：网址、读取时间、哈希、正文，报告引用的那段高亮；可以打开原网页对照，但核对以快照为准 |
| 交付核对 | 报告的引用按类型标注（网页 / GitHub / 本地），每条都能点开快照。引用和快照不一致时交付被拦下，Owner 自动补查 |

## 规则

1. **计数**：一次搜索算 1 次，一次抓取算 1 次，按事务累计。上限写进约定，确认即授权；超过上限必须在右侧问你。
2. **抓取范围**：只读不含账号密码的 http(s) 网址（沿用现有服务的检查）。正文最多存 6 万字，超出的部分标"已截断"，截断部分不能被引用。
3. **数据流向**：搜索词和网址会发送给 DeepSeek，由它的服务器去读取网页。约定里明确告诉你；事务的目标原文、本地资料内容不会随搜索发出。
4. **线索**：模型凭记忆或自带搜索给出的网址只算线索，Studio 重新抓取存档后才能引用；抓取失败就标"线索未能核实"，不进报告。
5. **网页内容是数据**：快照里的任何文字都不会被当作指令执行（沿用现有派工规则）。
6. **快照不随原网页变化**：原网页之后改了或删了，报告仍以读取时的快照为准，快照写明读取时间。
7. **费用**：用量计入设置里的"Owner 调研"来源，受全局月度上限约束。全局上限先到时，按第 1 条的方式在右侧问你。

## 状态与存储

- 联网通道的开关、密钥、月度上限、用量：现有 `WebSearchService`，不变。
- 每件事务的联网上限和已用次数：写在事务记录里（约定的授权一节），由 Owner 记录唯一持有。
- 快照：`资料/网页/<域名>-<哈希前 8 位>.md`，文件头记网址、标题、读取时间、整页 SHA-256、是否截断。
- 执行会话仍以纯文本方式运行，输出搜索请求和抓取请求；不把 `web_search` 工具直接交给模型，这样每一次调用都经过 Studio 计数和存档。

## 已定（2026-11-27 用户确认按默认）

1. 每件事务默认联网上限 20 次（搜索、抓取各算 1 次），可在 Owner 设置里改。
2. 用到上限时，在右侧问是否追加 10 次；60 秒无回应就停止联网，用已有资料继续。
3. 第二个接入的通道：GitHub 讨论与代码搜索（issue、PR、代码搜索），复用已保存的 GitHub 凭证。论文和内嵌浏览器读取排在之后。

## 验收

真人在真实应用中完成：

1. 在 Studio 设置里启用联网搜索，在 Owner 设置里看到"公开网页 · 已就绪"和默认上限；
2. 交办 Ibex 与 PicoRV32 对比，约定里看到"查公开网页 · 最多 20 次"和数据流向说明，确认一次；
3. 运行中在取证记录里看到搜索词和抓取的网页，计数随之增加；
4. 打开报告里的一条网页引用，中间显示快照并高亮引文；
5. 手工改动一份快照里被引用的文字，交付核对拦下这条引用；
6. 把上限改成 2 次再交办，用完时右侧出现追加请求，60 秒无回应后事务继续并在报告里注明。
