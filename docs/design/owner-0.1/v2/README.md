# Owner 产品设计 v2 · 逐页效果图

2026-11-21。依据 [Owner 产品定义](../../../features/ai-employees.md) 第一至六节绘制。全部数据为示意；源文件 [product.html](product.html)，PNG 由该文件逐屏渲染。

**设计主线：Owner 是负责人，不是聊天。** 每屏先回答这件事做到哪了、卡在哪、在等谁、交付了什么；右侧聊天只是你和负责人沟通的渠道。

| #     | 页面 / 功能                                                                                                                    | 要点                                                                                                             | 开发版现状                           |
| ----- | ------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| 01    | [入口 · 零事务](01-entry-empty.png)                                                                                            | 顶栏进入；列表层左侧固定侧栏；中间直接交办并回显保存位置；三步说明 Owner 的工作方式                              | 已做                                 |
| 02    | [列表 · 我的事务](02-list.png)                                                                                                 | 按等我确认 / 等我提供资料 / 进行中 / 已交付分组；每行一句话写清等你什么或 Owner 在做什么；顶栏只计真正等你的事务 | 已做                                 |
| 03    | [约定卡](03-agreement.png)                                                                                                     | 发出目标即建档；带版本的约定：目标、范围、交付物、验收依据、时间限制、来源、保存位置；确认一次才派工             | 已做（无约定版本号）                 |
| 04    | [执行中](04-in-progress.png)                                                                                                   | 事务 / Owner 动作 / 执行会话三种状态分开；当前步骤写清问题、负责人、为什么、交回什么；进度时间线                 | 已做                                 |
| 05    | [待决卡](05-decision.png)                                                                                                      | 只在影响约定或交付时问你；为什么问、已查事实、选项与影响；只有明确选择才算决定                                   | 未做（需新增待决数据与约定改版流程） |
| 06    | [交付](06-delivered.png)                                                                                                       | 写入并核对引用后才显示已交付；核对结果与打开方式                                                                 | 已做                                 |
| 07    | [文档标签 · 引用定位](07-evidence-tab.png)                                                                                     | 侧栏文件与“本地证据”在中间开标签，高亮引用行；右侧仍是同一 Owner                                                 | 已做                                 |
| 08    | [授权本地目录](08-grant-directory.png)                                                                                         | 选目录后先说明准确范围、会发生与不会发生，再授权；只读、仅本事务、可撤销                                         | 已做（A 尚不读取，弹窗如实说明）     |
| 09    | [Owner 设置](09-settings.png)                                                                                                  | 默认保存位置、常用参考目录登记、常用来源、交付格式、提醒；只定默认值，不授权                                     | 已做（无系统通知与声音提醒）         |
| 10–12 | [复制 Owner 诊断](10-diagnostics-button.png) · [复制后](11-diagnostics-copied.png) · [出问题时](12-diagnostics-on-failure.png) | 看板标题行右侧复制当前事务诊断；问题卡片里并排一份；复制后说明包含与不包含的内容                                 | 已做                                 |
| 13    | [执行会话分工](13-execution-sessions.png)                                                                                      | 看板列出 A/B/C 各负责什么、为什么续用或新开、状态与 Agent；同一时间只运行一个                                    | 未做                                 |
| 14    | [派工判断](14-dispatch-decision.png)                                                                                           | 每次派工写明交给哪个会话及原因、本步问题、可用资料、交回要求、完成标准；按派工单验收                             | 未做                                 |
