## 不变的规则

- 绑定可视浏览器 Tab 的任务仍禁用不可见搜索，在可视浏览器里搜索（`local-claude-code-backend.ts` 现有规则）。
- 搜索和读取网页不能证明网页上的操作已完成；发布、登录等结果仍由可视浏览器核验。
- 没有 DeepSeek Key 或服务不可用时，本地功能全部正常，Agent 只是看不到这两个工具。
- 密钥沿用现有本机凭证文件，不进系统钥匙串、不随工作空间同步。
