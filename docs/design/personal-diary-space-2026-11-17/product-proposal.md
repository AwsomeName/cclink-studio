# 我的空间 · 日记项目产品设计

2026-11-21 定稿，供实施与验收。每张效果图只展示一个页面。图内正文、路径和运行状态为示例。[实施计划](implementation-plan.md) · [目录与迁移约定](directory-and-migration-memo.md)

## 三条用户验收流程

1. 首次使用：选默认目录或已有目录，独立决定是否连接 Git。核对并确认，进入所选项目；重启后仍打开它。仅查看初始化页不会创建日记、拉取、上传或运行任务。
2. 日常使用：从首页续写当天原文，切回文件导航后继续编辑；查历史和周计划；修改任务的章节要求，保存并手动运行，用实际产物核对标题、次序和路径。
3. 换电脑：用独立副本接入同一仓库，核对日记根、附件和任务定义。任务默认本机停用；明确启用后才调度。断网、原目录移动、工作树有修改时仍能恢复现场。

## 项目的归属

「我的空间」是可改名、保持固定的默认日记项目。只有一份当前项目目录，项目首页、文件树、当前项目会话、终端及任务均使用它。日记子目录在项目内，例如项目为 woniu-forward，日记根为个人计划。普通公司项目使用实际名称。重复打开同一目录复用已有项目。

顶栏管理已打开项目、新建／打开、历史项目、Studio 设置及会话面板控制。左侧单栏提供项目首页、日记、计划、定时整理、文件、会话、工具。文件树原位切换。项目设置位于项目首页。Studio 管理账号、角色和全局偏好。

## 首次确认本地路径，Git 可选

| 选择           | 确认后的行为                                                                                           |
| -------------- | ------------------------------------------------------------------------------------------------------ |
| 默认目录       | 显示实际绝对路径，例如 ~/CCLink Studio/我的空间。该位置已有项目时识别并核对。                          |
| 已有目录       | 由用户选择项目根，优先从项目配置识别日记相对目录与时区。旧项目只在所选范围查候选，显示最近日记供确认。 |
| 任一目录 + Git | 可在首次配置或稍后连接远端。已有 origin 时预填远端和分支。未配置仍可完整使用本地项目。                 |

空目标可克隆到选定位置；已有匹配仓库只审阅差异后操作；非空非仓库、远端不匹配、分叉、有未提交内容时保留现场，提供独立新副本或继续本地使用。配置地址和保存设置都不触发上传。上传由用户在 Git 中审阅、提交并推送。取消或失败保留上一次已确认的项目与资料。旧版外部关联显示两边实际路径与最近日记；有内容冲突时让用户选择。曾连接的路径失联直接进入重新定位。

## 日记与任务写入规则

日记与专用附件相邻，默认写入 个人计划/YYYY/MM/MMDD\_周X.md；周计划放在当年「周计划」中。按项目时区确定首页的今天，定时运行以实际计划发生时刻及任务时区计算目标。两者目标不一致时显示路径，要求核对。写入前识别下划线、短横线等已有兼容名称，多个候选由用户选择。并发或重复执行保留原内容；模板降级标注生成失败。

任务编辑使用现有自然语言指令。用户可写“依次写三个二级章节：上周进展、遗留问题、本周计划加本周一日期；遗留问题用表格，未知原因写待核实”。参考 Markdown 提纲可选，显式任务要求优先。日期命名可以用自然语言描述，图中的花括号仅示意，指令区没有新增变量语法。示例三章不是内置周计划格式。保存影响以后手动和定时运行；已生成文稿及正在运行的指令快照保留。共享任务定义变化按原规则重新确认，历史中可查看实际产物。

项目配置、共享任务定义可随 Git 携带。选中的本机项目、认证材料、启用、权限和运行账本由本机管理。发现共享任务、在首页关联任务、在设备启用、立即执行分别有独立结果。按已保存的任务 ID 恢复匹配的定义，缺失项可重新选择；旧设备运行权不随仓库复制。
