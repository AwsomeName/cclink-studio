# 我的空间 · 进入与首页逻辑（2026-11-23 梳理）

> 本文只描述「怎么进入我的空间、进入后看到什么」。页面细节见 `product-logic.md` 与 `mockups-v2/05–08`。

## 1. 一句话规则

**「我的空间」是顶栏第一个固定标签，名字永远是「我的空间」；点它或启动 Studio，就进入「今天」，直接看到今天的日记。**

## 2. 进入入口（只有这三个）

| 入口 | 结果 |
| --- | --- |
| 启动 Studio（默认「启动时打开我的空间」） | 我的空间 / 今天 |
| 点顶栏 📌 我的空间 | 我的空间 / 今天 |
| 左侧「今天」、状态栏「本地 · 我的空间」 | 我的空间 / 今天 |

其他项目标签、历史项目里如果点到的正是我的空间所用目录，也直接进入 📌 我的空间，不会再出现第二个同目录标签。

## 3. 进入后显示什么（按顺序判定，命中即停）

| # | 状态 | 判定 | 显示 |
| --- | --- | --- | --- |
| 1 | 未设置 | 还没有确认过目录 | 首次使用四步（确认前不写任何文件） |
| 2 | 失联 | 绑定目录不存在或身份不一致 | 重新定位（原资料保留，不新建空目录） |
| 3 | 旧版外部日记链接 | 升级前的链接仍指向另一目录 | **今天照常显示该目录里的日记**；上方一条提示可「将原资料目录用作项目目录」，不挡内容 |
| 4 | 可用 | 其余 | 今天（见第 4 节） |

AI 不可用、同步失败都不改变上述状态，只在今天页和状态栏提示。

## 4. 今天页（效果图 05–08）

| 今天的日记 | AI | 显示 |
| --- | --- | --- |
| 已有 | — | 07：正文各章节摘要，标签「HH:MM 自动起草」「已保存」，继续写 / 让 AI 修改 |
| 没有，正在起草 | — | 06：「AI 正在自动起草 · HH:MM 定时」，当前步骤，取消 |
| 没有，未到点 | 可用 | 05：「HH:MM 自动生成今天的草稿」，现在起草 / 空白模板 / 修改时间 › |
| 没有，已过点且失败或错过 | 可用 | 当天第一次进入自动重新起草一次（用户取消的不自动重来） |
| 没有 | 不可用 | 08：「AI 起草不可用」+ 原因，去修复 / 空白模板（未经 AI 起草） |

下方固定两行：本周计划（文件名 · 打开 ›）、同步（状态 · 查看 ›）。

## 5. 更换我的空间所用目录

目标：只在两处发生，且都要用户核对后确认——首次使用第 1 步；项目设置 › 更换目录。旧版链接提示与失联重新定位都走同一个核对页面。确认后标签仍叫「我的空间」，原目录文件原样保留。

现状还多出两个入口，待确认后收敛：

- 「新建 / 打开」里的「将当前工作空间用作我的空间」：一键把当前项目设为我的空间，没有核对步骤。
- 旧同步页（PersonalDiaryGit）克隆或连接后的「确认后『我的空间』改用…」。

## 6. 普通日记项目

类型为「日记」的其他项目复用同一首页，但标签和路径用项目名、左侧分组叫「日记与计划」、没有 📌，也不参与第 3 节的首次使用 / 迁移判定。
