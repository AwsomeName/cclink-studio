# 我的空间 · 进入与首页逻辑（2026-11-23 第三版）

> 效果图：`mockups-v2/01–08`、`22-import`、`23-settings`。

## 1. 三条规则

1. **我的空间只用自己的固定目录 `~/CCLink Studio/我的空间`，不能设置成别的路径。**
2. **历史日记只能「导入」：复制进来，原目录不移动、不修改，也不会变成我的空间。**
3. **同步填我的空间自己的 Git 项目地址；新电脑填同一个地址就能取回。**

一个目录只属于一个项目。我的空间不会再接管、合并或改写其他项目。

## 2. 进入

启动 Studio、点顶栏 📌 我的空间、点左侧「今天」，都进入「我的空间 / 今天」。

| 状态     | 显示                                                          |
| -------- | ------------------------------------------------------------- |
| 还没设置 | 首次使用四步：导入历史（可选）→ 同步（可选）→ AI → 核对并确认 |
| 已设置   | 今天（效果图 05–08）                                          |

固定目录被删掉时，回到首次使用重新创建，可以再导入。不再有「重新定位」或「更换目录」。

旧版本曾把我的空间指到其他项目目录（例如 `woniu-forward`）：升级后自动解除这个关联，原项目原样保留，并回到首次使用；第 1 步默认选「从历史目录导入」，并提供「从上次使用的目录选择」。

## 3. 导入历史

- 入口：首次使用第 1 步；之后在「项目设置 › 从历史导入…」，可多次导入。
- 选一个文件夹：如果里面有日记子目录（项目设置里的日记目录、`000-个人计划` 或 `个人计划`），复制这个子目录；否则复制所选文件夹本身。
- 先只读核对：日记篇数、最近一篇、将复制多少文件、跳过多少同名文件。
- 复制到 `我的空间/个人计划/`，保持原来的相对路径；同名文件不覆盖；隐藏文件和符号链接不复制。

## 4. 同步

- 首次使用第 2 步或左侧「同步」填 Git 项目地址；不填也能本地使用。
- 首次使用填了地址：确认后先取回远端已有内容，再导入历史、创建内置任务（远端已有的任务直接沿用，不重复创建），最后上传。
- 只同步我的空间自己的目录；其他项目继续用它们自己的 Git 面板。

## 7. 普通日记项目

类型为「日记」的其他项目用同一个首页，日记放在项目自己的目录里；标签用项目名，左侧分组叫「日记与计划」，没有 📌，没有「同步」和「导入历史」。
