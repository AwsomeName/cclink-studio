## 定位

「文件」用来查看我的空间项目在磁盘上的真实内容，也是日记页覆盖不到的内容的入口：项目记录、资料、模板、会话记录、附件，以及仓库中的其他目录。它展示原文件，不另建数据。

## 范围

- 根目录就是我的空间的项目目录。
- 默认隐藏 `.git`、`.cclink-studio` 等以点开头的内部文件。
- 其他功能不得默认往我的空间写目录。Owner 事务的新目录放在 `~/CCLink Studio/Owner 事务`；已有事务按原记录位置继续使用，用户可自行移动整个文件夹后在 Owner 中重新定位。

## 布局（展开式）

- 点击左侧「文件」后，项目导航保留在上方，文件区在其下展开；不再替换整个左栏，也没有「‹ 项目导航」返回按钮。
- 文件区顶部固定快捷入口：今天的日记、本周计划、日记目录、资料。
  - 今天的日记：已存在则打开；不存在则回到「今天」页（新建走今天页，保证命名与不重复）。
  - 本周计划：打开最近修改的周计划。
  - 日记目录、资料：在文件树中展开并选中；资料目录不存在时不自动创建。
- 下方是完整文件树。切回其他页面再回来，展开状态与选中位置保持。

## 打开时定位

- 从日记、计划或编辑器切过来时，选中正在查看的文件（自动展开祖先目录）。
- 没有打开的文件时，展开日记目录下的当月目录并选中今天的日记；今天还没有日记则选中当月目录。

## 操作规则

| 操作 | 规则 |
| --- | --- |
| 新建文件或文件夹 | 建在当前选中的目录中 |
| 新建当天日记 | 走「今天」，不在文件树中按日期手工新建 |
| 改名或移动日记 | 若改后不再符合 `年/月/MMDD_周X.md`（或兼容的短横线名），先提示「历史与起草将不再识别这篇」，确认后执行 |
| 删除 | 移到废纸篓并确认；不永久删除 |
| 粘贴附件 | 放进当前日记相邻的资源目录 |

## 与 Git、AI 的关系

文件树为以下文件加标记，与同步页、改动报告一致：

- 「未上传」：Git 工作目录中有未提交改动的文件。
- 「AI 改」：AI 改动报告中尚未撤销的文件。

## 验收

1. 打开我的空间的「文件」：项目导航仍在，文件区在下方展开，当月目录展开、今天的日记被选中。
2. 点击四个快捷入口，分别打开或定位到对应内容。
3. 在日记页打开一篇历史日记，再点「文件」，树中选中该文件。
4. 把一篇日记改名为 `杂记.md`：出现确认提示；取消后文件不变。
5. 新建 Owner 事务后，我的空间根目录不出现「Owner 事务」。
