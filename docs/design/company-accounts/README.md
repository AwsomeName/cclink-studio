# 账目工作台设计示意

2026-10-09。状态：交互示意，未实现。所有金额、交易、凭证、身份和交接结果均为演示数据。

后续用户要求重新设计核心产品功能，最新提案见 [AI 账目助理核心产品设计](../../features/company-accounts-product-design.md)。这里的六页仍为暂存草稿，尚未按最新入口和流程更新。

最新方案基于官方公开功能和操作文档重做，六个页面独立展示，不需要通过一个页面的左侧菜单寻找。报表、项目账、业务单据为主线；对话准备草稿，结构化表单提交。点击仅改变示意状态，不创建账目、导出、备份、转账或提醒。

1. [报表中心](finance-reports.html)：年、月、周、日切换，项目和账户筛选，合计、趋势与明细联动；年度资料缺失明确提示。
2. [项目账](finance-projects.html)：切换眼镜 A/B，预算、已确认业务费用、已付与待付及单据。
3. [报销申请](finance-claim.html)：AI 对话与结构化申请表，核对后提交审批。
4. [审批与付款](finance-approval.html)：人工批准、退回理由、批准后的付款登记和部分付款。
5. [流水与凭证](finance-matching.html)：流水关联已有业务，避免报销费用重复计入。
6. [导出与交接](finance-handoff.html)：报表、代账资料、交接、返回结果及备份。

组合源文件：[新版页面源](revised-pages.html)。[旧版](accounts-preview.html)保留作为历史草稿，不代表最新方案。

报表示例仅覆盖 9 月：收入 80,000 元、支出 32,800 元；项目 A 公司已付 20,000 元，另含已批准待付报销 800 元，项目 B 已付 8,000 元，公共费用 4,800 元。报销申请与审批页为 10 月示例，不能混入 9 月报表。对话操作是脚本演示，不是实际 AI 调用。此处没有真实多人身份、权限或财税核算实现。

示意验证：六页在 1024、736 和 360 像素宽度渲染，无页面横向溢出；已检查年/月/周/日报表、项目与账户筛选、报销提交、批准前付款禁用以及部分付款状态。已查看六页截图。此验证仅针对示意，不代表 Studio 功能或财税能力通过验收。
