# 账目工作台设计示意

2026-10-09。状态：历史效果草稿；首版实际界面已按一个工作台实现。所有效果稿金额、交易和凭证均为演示数据。

最新产品范围已经收缩为 [公司账目首版产品设计](../../features/company-accounts-product-design.md)：一个账目入口、一个工作台，以及“导入与核对、月度汇总、导出与备份”三个任务区。月度汇总由用户选择一个月份，支持历史月份，不扩展为日周年度报表。

报销与付款、待收待付、预算提醒和多周期报表已从首版删除，对应占位页不再保留。现有以下效果稿只用于继承 Studio 的视觉方向，页面导航和信息结构不再代表最新产品范围：

- [经营概览草稿](v3-reports.html)
- [项目支出草稿](v3-projects.html)
- [记录核对草稿](v3-ledger.html)
- [导出与备份草稿](v3-handoff.html)

实际实现已把四张草稿合并成一个账目工作台，没有继续补独立页面。首次进入只显示“开始使用”和“从备份恢复”，点击开始后直接进入导入，不出现公司、账户、分类、项目或会计期间配置向导。

能力范围与实施顺序见 [最小开发计划](../../features/company-accounts-development-plan.md)。
