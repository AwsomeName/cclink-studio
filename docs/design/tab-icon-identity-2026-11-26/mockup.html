每类标签用什么来区分

类型样子身份从哪来拿不到时怎么办
远程桌面
家 公
设备名的首字（中文 1 字 / 英文 2 字母），颜色由设备 ID 固定算出；可在右键菜单「改简称和颜色」。绿点 = 已连接。 还没选设备：空白显示器；只有地址：用 IP 末段，如「.23」。
网页
A
优先用网站自带图标；没有时用网站名或域名首字母 + 按域名固定的颜色（本地端口不同算不同站点）。 空白新标签页：地球线性图标。
同站不同账号
张 李
已保存的网站账号：右下角圆形小徽标，显示账号名首字，颜色按账号固定。 未保存的账号草稿：不加徽标。
文档 / 文件
MD
按扩展名换图标（Markdown、表格、PDF、代码…），普通标签本来就有文件名。 未知类型：通用文件图标。
Terminal
标签名显示工作目录末级（如「cclink-studio」）；固定后图标颜色按目录固定。 没有目录：默认颜色。
其余（定时任务、设置、会话…）
只把 emoji 换成同风格线性图标，靠标签名区分。 —

需要你拍板

1
固定标签用方案 A（图标里带简称）还是方案 B（图标 + 短名）？
建议 A：宽度不变，完整名字看悬停。
2
远程桌面的简称和颜色允许手动改吗？
建议允许，放在标签右键菜单；默认自动取设备名首字。
3
同站不同账号要不要加账号小徽标？
建议要，只对已保存账号显示。
4
这次只改远程桌面和网页，还是连文档、Terminal、emoji 一起换？
建议先做远程桌面 + 网页 + 换掉 emoji，文档按扩展名和 Terminal 着色放第二步。

实现时要注意

  • 远程桌面的设备名现在只在连接中可读（会话视图），标签本身只存地址；要让断开后也能显示简称，需要把「简称 + 颜色」存进标签（随工作空间恢复），状态仍归标签存储一处所有。
  • 网页字母块用页面已有的地址和标题算，不新增网络请求；网站自带图标加载失败时自动退回字母块。
  • 账号徽标用已有的网站账号名称，不读取任何登录凭证。
