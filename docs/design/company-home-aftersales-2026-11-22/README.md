## 推广和跟进客户去哪里

- 侧栏两项：**推广**、**客户与售后**。首页底部“推广与客户”的三个按钮和待办里的按钮都直达这两页。
- **推广**：可以讲的内容（买家反馈需对方同意才引用；未验证的改进不对外宣传）→ 审阅与批准（事实核对、按账号批准）→ 本周发布及带来的咨询和下单。
- **客户与售后**：意向咨询和售后工单在同一列表，可筛选。售后显示订单号和购买天数，拟回复引用保修政策和使用说明；价格、企业报价和退款只由你本人处理。右侧是本月售后统计和反复出现的问题（镜腿松动已转给二代研发）。

## 复用现有界面

- **账号与登录**：设置 · 网站与账号（现有 `WebResourcesSidebar` 的文案、状态、确认登录、运营矩阵与凭证边界）；账号浏览器环境（工具栏“账号 · 名称”）；文章发布的“交还 Agent 并继续”。
- **退款**：打开网店后台该订单页面，由你本人点击同意，Studio 只读回订单状态（ADR 0016：付款与退款转人工）。
- **收支**：公司账目，只计已确认，按业务归属，导出给代账。

新增的部分：首页聚合、你自己添加的待办、网店订单读取、推广和客户与售后两页（见[产品愿景](../../features/company-marketing-product-vision.md)，该文档仍按上市前招募写，确认本版后需改为销售与售后）。
