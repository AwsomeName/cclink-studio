规则

操作 结果
单击图片 → 拖动手柄 等比缩放；最小 48px，最大铺满所在区域（单元格或正文）。拖回铺满即恢复为普通 ![]()。可撤销。
双击图片 弹出原图查看；超过 5 MB 未自动加载的图在这里加载。
选区/文件发给会话 工作区内的本地图片自动作为附图挂上，最多 5 张，可逐个 ✕ 去掉；其余和网络图片只给路径，并提示。
不做 档位浮条、裁剪、旋转、对齐/环绕、单独设高度、保存时压缩原图。

验收（真实应用里能做到）

  1. 单击表格里的图片，拖手柄缩到约 160px；保存后源码为 <img src="…" alt="…" width="160">，关闭重开仍是 160px，文档仍可正常编辑。
  2. 再拖回铺满：源码回到 ![…](…)；⌘Z 能撤回每一次缩放。
  3. 双击图片：弹出原图并显示原始尺寸；Esc 关闭，文档无改动。
  4. 选中含 2 张本地图片的段落发给会话：输入框出现文字片段 + 2 张附图；Agent 能描述图片内容。
  5. 以上操作后磁盘上原图文件的哈希不变。
