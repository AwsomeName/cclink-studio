Markdown 表格：飞书式编辑体验

目标：在 Studio 的 Markdown 文档（含“我的空间”日记）里，像飞书文档那样直接用鼠标增删、移动行列， 不必记右键菜单或快捷键。边界：文件仍是标准 Markdown 表格，任何 Markdown 存不下的东西（合并单元格、颜色、列宽、单元格内换行）都不提供，保存后不会悄悄丢失。 所有操作和现有右键菜单是同一组命令，只是多了可见的入口。

Enter 跳下一格、↑↓ 跨格 本次 见待确认 D2。
按列排序 下一步 重排数据行；中文按拼音、数字按数值。见 D3。
从飞书 / Excel 粘贴区域 下一步 解析剪贴板 HTML 表格或制表符文本，按格填入。
拖动调整列宽 待定 Markdown 没有列宽。见 D1。
合并单元格、单元格颜色、冻结、筛选、公式 不做 标准 Markdown 存不下；做了会在保存或别的工具里丢失。需要时应换成多维表格类文件，不在本次范围。
单元格内换行、列表、多段落 不做 GFM 单元格只能单行；<br> 属于原始 HTML，会让文档落入“范围外语法”。

待你确认

D1 列宽拖动：Markdown 没有列宽。①不提供拖动（推荐，表格按内容自动排版，和飞书“自适应”一致）； ②允许拖动但只在本次打开有效，关闭即恢复；③把列宽写进文件里的 CCLink 注释——其他工具看不到、会产生 diff。现在编辑器里其实已经能拖列宽但不会保存，属于①②之间的不一致状态。
D2 Enter 行为：①跳到下方单元格，最后一行新增一行（推荐，类似表格软件，且不会产生存不下的换行）；②像飞书那样在格内换行——需要写 <br>，会让整篇文档变成“范围外语法”只能源码编辑，不推荐。
D3 首版是否带排序和粘贴：建议首版先做 ①–⑤ 的手柄、插入、菜单、拖动、框选；排序和 Excel 粘贴放第二步，避免一次铺太大。
D4 入口是否也出现在“我的空间”日记里：建议是（日记里的项目进度表正是主要使用场景），和普通 Markdown Tab 同一套实现。

验收（你在真实应用里能做到）

  1. 打开今天的日记，鼠标移到项目进度表上，能看到行列手柄和“+”；移开后消失。
  2. 点两行之间的“+”插入一行、点“新增一行”追加一行；点列之间的“+”插入一列。保存后在源码/Git 里是标准 Markdown 表格。
  3. 点“计划”列手柄 → 设为居中，重开文件仍居中，源码分隔行为 :---:。
  4. 拖“硬件—喇叭”这一行到第一行数据位置，⌘Z 能撤回；不能拖到表头之上。
  5. 框选 2×2 单元格 → 复制 → 粘到飞书，得到 2×2 表格；⌫ 只清空这 4 格。
  6. 表头行的“删除行”“上移”置灰且有原因提示。
  7. 以上任一操作后，表格以外的内容逐字不变（沿用 A1 保真检查）。
