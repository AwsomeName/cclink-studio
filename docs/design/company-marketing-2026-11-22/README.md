## 这一页要讲清楚的事

公司项目侧栏的“市场与用户”（取代原“运营内容”）。一页从左到右是一条工作流：

1. **可以讲的进展**：从眼镜研发项目、我的空间日记和 Owner 交付物中挑出本周进展，标出处，给出受众和平台建议。未写入产品事实表的数字要先确认；属于不公开范围的内容标“不建议公开”。
2. **审阅与批准**：同一篇内容的知乎长文、小红书图文、B 站口播三个版本；对照产品事实表核对，冲突未处理前不能批准；按账号逐个勾选，账号来自全局网站账号库并显示登录状态；写明预期结果和会停下交给你的情况。下方是本周发布，“已公开”只在平台读回核验后出现。
3. **跟进感兴趣的人**：按意向分类（试戴、购买、合作、报名待筛选），显示来源内容、等待时长、拟回复和引用的事实。价格和上市时间只起草、由你回复；合作由你决定；报名按你的条件给出建议名单，由你确认邀请。

顶部是上市前目标：确认参加的试戴者（7/30）与招募漏斗、本周新报名、等你回复、关注者变化（读不到的写“未获取”）。底部是“本周什么有效”：报名来自哪篇内容、反复被问到的问题、下一篇可以讲什么。

右侧 Agent 栏默认收起，给三列让出宽度；需要时展开。

## 可操作的演示

打开 [marketing.html](marketing.html)：

- 切换平台版本标签。
- 点“改为 3.5 小时”处理事实冲突后，“批准并发布”才可用；取消勾选账号会改变按钮上的账号数。
- 批准后，本周发布列表出现执行中和排队的两项。
- 在跟进列表点“批准发送”，显示发送中，再显示已核验。
- 按意向筛选；第 1 列点“写成内容”。
- 底部评审栏：数据来源标注、重置、浅色/深色。URL 参数 `?clean=1`、`?notes=1`、`?theme=light|dark`、`?approved=1` 用于截图。
