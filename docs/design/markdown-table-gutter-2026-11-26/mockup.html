Markdown 表格控件：留白与按需出现

目标：表格四周有属于表格自己的留白，手柄和“+”只画在留白里，从不盖住上下文的标题、段落； 鼠标在正文上时控件不出现，靠近哪里才出现哪里的控件。 虚线框是预留区，仅设计图可见，实际不显示。

能力不丢失

控件变少后，原有操作都还在：右键菜单（插入 / 删除行列、对齐、删除表格）、 最后一行按 Enter 新增一行、拖动手柄排序、框选复制与清空。

只改“什么时候出现、画在哪里”，不改任何表格操作和 Markdown 写法。

3 · 产品逻辑

  1. 留白属于表格：表格外层预留上 22 / 下 26 / 左 28 / 右 26 px（替换现在的 margin: 1.4em 0 1.8em），所有控件坐标都限制在留白内。
  2. 悬停判定 = 表格 + 留白：GUTTER 与留白一致，不再向标题、段落外扩； 鼠标在别的块上时控件一律不渲染、不接收点击。
  3. 按距离分层出现：在单元格内 → 当前行、列手柄；靠近行/列边界的左侧/上方留白 → 对应位置的插入“+”；靠近下边或右边 → 追加行/列条。其余时刻不显示。
  4. 输入时让位：键入期间隐藏全部控件，鼠标移动后恢复。
  5. 视觉减重：列手柄 22×9、行手柄 9×22，静止时低对比，悬停变高亮；追加条改为 16px 虚线条。

4 · 需要你确认的点

  1. D1 追加条出现时机：建议“靠近下边/右边才出现”；另一选项是“鼠标进表格就出现， 但只画在下方留白里”（更容易发现，但更常亮）。
  2. D2 列手柄：建议只显示当前列；另一选项是表格悬停时全部列都显示（现状）。
  3. D3 留白代价：每个表格上下各多约 8–10px，表格多的文档会稍长。可接受吗？
