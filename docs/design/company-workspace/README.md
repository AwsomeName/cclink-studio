# 公司工作空间效果稿

日期：2026-10-14。对应 [已确认的公司工作空间产品设计](../../features/company-workspace-product-design.md) 和 [实现方案](../../features/company-workspace-development-plan.md)。使用方式为个人经营，AI 协作，财务、项目管理与运营同时纳入。用户已确认采用经营导航作为首版布局，收件箱只保留对比，不作为并行实施范围。

## 布局方案

- **经营导航**：已确定的首版。左侧固定公司总览、业务项目、财务、运营、资料与会话；中间处理业务，右侧复用 AI 面板。
- **经营收件箱**：仅保留对比。顶部公司导航；首页先处理待办，旁边显示业务上下文，下方显示经营账，不进入当前实现方案。

两种方案都先展示需要处理的事项，并支持相同业务路径。布局对比不扩大功能范围。

## 可点击的评审路径

1. 打开 [预览](preview.html)，从“查看卡点与下一步”进入产品介绍稿工作。
2. 关联示例试戴记录，让 AI 准备计划，接受并准备示例稿件；先查看稿件，再点击验收。
3. 进入运营，检查单篇文章的发布范围，开始演示执行。提交结果未知时只显示核验动作；核验后查看示例公开结果证据。
4. 展开发布计划任一步，查看执行者、动作、进入条件、状态、完成证据、等待原因和允许下一步。正文、每张图片、平台字段、保存、提交和结果核验分别展示。
5. 在财务查看测试服务原件，再人工确认；月度支出从示例 ¥1,640.40 增加到 ¥1,820.40，项目支出同步更新，收入保持 ¥3,000.00。
6. 从业务项目进入关联支出、运营内容和资料；使用底部布局切换控件比较两种方案。设计控制支持舒适或紧凑密度。

项目草案与 AI 工作草案只展示下一步建议，不创建真实公司项目或启动真实执行。
