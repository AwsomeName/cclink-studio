# 一款外形从新描述到 STEP · 在 Mac 上验收

开发版入口为本地项目的 **工具 → 产品造型**。输入自己的描述，Studio 把它交给当前本地 Agent。Agent 为这次输入生成有序轮廓点及高度，Studio 启动本机 Blender 建模。支持 XY 平面上 3–16 个顶点的凸多边形，沿 Z 直线拉伸，修改一个已有顶点，沿 +Z 做开口底壳。适合直壁盒、削角仪表壳、多边形底座。要做圆弧、凹形或自由曲面时，请保留新需求供后续造型能力使用。

## 准备

1. 从当前仓库运行 `pnpm dev`。在 Studio 打开一个本地项目；要做盲测，可以新建空项目。确认 Agent 面板中的本机 Agent 能正常对话。本次实测使用本机 Codex。
2. 本机 Blender 放在 `/Applications/Blender.app` 或 `~/Applications/Blender.app`，FreeCAD 放在 `/Applications/FreeCAD.app`。如 FreeCAD 在自定义位置，在 Studio 设置的 CAD 页面指定 FreeCADCmd。要在 Studio 内直接查看 STEP，在同页将转换后端选为「本机 FreeCAD」；Blender 生成的 GLB 可直接预览。
3. 左侧展开「工具」，点「产品造型」。在「我的外形描述」写用途、俯视轮廓和长宽高。可以说哪一角要削去多少。验收人自己出题，打开空项目后才定尺寸。

## 一次连续操作

| 在 Studio 做什么 | 需要亲眼核对的结果 |
| --- | --- |
| 点「用 Blender 生成一款外形」，查看右侧 Agent 的工具确认卡并允许 | 卡片显示本次轮廓点和高度，工作台随后打开可旋转的 3D 外形。右侧可看顶点编号与坐标，项目中新建父版的 `shape.blend`、`shape.glb` 和 `revision.json` |
| 在「锁定侧面」选一条边，在「修改顶点」选不属于该边的一个角。输入自己的改法，比如沿 +Y 移动 2 mm，点「锁住侧面，生成子版」 | 俯视图绿色边与橙色点对应自己的选择。确认卡列锁定边号、目标点号和新坐标。回读结果列锁定面的最大偏差、修改点的前后值和独立子版 ID。父版文件仍可打开 |
| 记下子版 ID。关掉 Studio，重开同一项目；打开原标签，或从「文件 → 产品造型 → 子版 ID → shape.glb」回来 | 显示「子版外形」，父版 ID、锁定面和追改坐标与退出前一致。也可以直接用 Blender 打开这个子版里的 `shape.blend` |
| 在「子版做结构」填壁厚和底厚，点「用此子版生成 FreeCAD 和 STEP」。在确认卡比对完整源版本 ID 后允许 | 另一个输出目录出现 `housing.FCStd`、`housing.step` 和 `check.json`。其中 `sourceId` 指向刚修改的子版，`sourceBlendHash` 等于子版记录里的 `blendHash`。产品驱动重新打开已核对摘要的 .blend，按求值后的几何重建，并从 STEP 回读 |
| 用 FreeCAD 打开 `housing.FCStd`，双击 `Dimensions`，修改 B1（Wall），重算；另开空白文档导入原 `housing.step`，定位相同截面 | 原生模型的内腔随壁厚改变。STEP 中可以量到刚才改过的角。若截面两侧均为平行直壁且外宽保持，左右各向内增厚 1 mm，内宽应少 2 mm。要获得新壁厚的交换件，回到同一子版输入新壁厚再次导出 |

回读还核对内外轮廓顶点、底面、闭合有效实体数和体积。若壁厚消掉某个边角、底厚达到外高或源文件已在外部编辑，工具会报告原因。回到原子版调参数即可重试。工具不覆盖已发布版本。
