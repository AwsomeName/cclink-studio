# 产品造型工作版面 · 第一版开发方案

**完整第一版交付条件**　设计者在本地项目里现场输入一句话，Studio 调用当前 Agent 和本机 Blender，生成三个能旋转、能重新打开的外形。设计者选中一个，锁住要保留的部位，用第二句话修改，关掉 Studio 后还能从这个版本继续。对其中符合条件的外形，设计者能进入 FreeCAD 调整结构、导出 STEP 并读回。

**当前开发版**　单款凸多边形直壁壳已支持现场生成、锁面改点、重启续用、子版做结构和 STEP 回读。三款比较、自由曲面交接与更多锁定方式属于后续开发。[Mac 操作与实测](first-chain-mac.md)

## 入口和归属

采用**当前设计文档的工作版面**。已有本地项目内从「工具 → 产品造型 → 新建设计」进入。电子开发项目可以多放一个快捷入口。公司或通用项目也能打开同一份设计。每份设计一个标签，同项目可有多份；切到需求文档或 PCB 会回到相应内容版面。在文件树重开设计，就找回外形、选择和改动。项目类别继续决定首页与侧栏，「产品造型」没有全局模式开关。仓库已有公司与电子开发项目打开同一 STL 的应用验收。[已有验收](../../../../testing/typed-workspaces-2026-11-19.md)

| 用户眼前 | 用户操作 | 系统交付 |
| --- | --- | --- |
| 新建设计 | 用自己的话描述产品。选「优先探索外形」或「需要接着出 STEP」 | 前者可用自由曲面；后者优先采用已有 CAD 对应建法。若某句与已支持的建法冲突，列出该句并让用户选保留原意或放宽条件。保留原文和用户的选择 |
| 三款同尺度外形 | 点自己原话中的一句，同时查看三款怎样做到；选择前查看各款的 CAD 预计范围 | 每款显示原话、对应部位和几何证据。不能测的风格要求交给人判断；未满足的硬要求标为待修，不计为合格候选。CAD 卡明确预计能接哪些零件、哪些曲面要补、依据和待核项 |
| 选中一款 | 点挂钩，分别选择「形状不变」「位置不动」「只锁指定尺寸」；另选拾音口并输入追改 | 父版留存，子版上叠加旧轮廓、标出锁定部位和目标，列出前/后值、允许误差、未达项。违反锁定时保留诊断预览，让用户改要求或主动解锁后重试 |
| 进入 CAD | 确认零件、尺度、坐标基准、要保留的面及允许偏差 | FreeCAD 实际重建所选版本，与 Blender 求值后几何比较，返回实测、局部交接、需重建或尚未完成检查 |
| 改结构与导出 | 选开口面、底厚、壁厚和输出范围，检查预览后写出新文件 | 参数原生源件 .FCStd 可重开、再改；交换件 STEP 在新文档回读，展示实体数和关键尺寸。只通过局部时列明可交接的部位 |

### 每一款如何回答同一句原话

选款页以用户原话为索引。每条可核对的要求保存原句片段、作用对象或面、参照系、检查方法、用户阈值和测量来源；值从该候选重新打开的 Blender 几何取。点原句或卡内行，三款同步高亮对应部位。以下数字是界面示意，实际项目由用户输入和模型回读决定。

| 原话 | 核对依据 | 在画布上看什么 |
| --- | --- | --- |
| 挂在显示器上沿 | 指向挂钩/夹座，显示开口、接触面和相对屏幕上沿的安装方向。缺屏厚时标「待补屏厚」 | 夹座位置可见；给出夹口只能证明设计里留了这个空间。真机尺寸和实际装配另行确认 |
| 给居中摄像头留至少 30 mm 净宽 | 用户确认摄像头避让区的中心、工作深度和高度范围，在该范围测最窄净宽；图例取 A/B/C 分别 36/44/32 mm | 同一基准画出避让框、两侧边界和最窄截线；缺范围时显示假设，进入工程前复核 |
| 两端朝向我 | 在项目正面基准下读左右拾音口的朝向轴，在俯视图显示向前分量及内偏角；只指定“朝我”时，角度属于方案选择 | 显示器前沿和左右方向箭头；几何朝向可检验，拾音性能需后续试验 |
| 总宽 160 mm | 读取安装姿态下整款外形沿宽度方向的极值差 | 端点和尺寸线；三个候选共用比例。同一世界坐标系，禁止为凑宽度单独缩放预览 |

选择前提供**预计能进 CAD 的范围**。例如折面方案的单件主壳有直线轮廓和拉伸记录，可尝试整件重建；分体方案的夹座有映射，两侧曲壳需补；一体连续外皮含无对应操作的局部形变，可作为外形参照。预测来自该候选当前操作及其依赖，每款都能点开理由。申请 STEP 优先时，若三款无法同时满足硬限制和 CAD 要求，显示实际可行数量和卡点。候选卡统一标「待 FreeCAD 试建」，用户选中后才进入工程检查。

### 锁住一处，改另一处

三种锁可独立选，尺寸锁指定测量位置和数值。形状锁在部位局部坐标系比较求值后的外形，允许部位整体刚体移动；位置锁在选定的机身基准中比较安装原点和姿态，允许未锁定的局部形状变化。只锁尺寸时，其余自由度可变。基准丢失、对象被替换且不能可靠匹配时，提示重新指定对应部位。用户选择的基准和允许偏差随版本保存。

图中选择 B 款后，同时锁住后夹座的形状与安装位姿，目标选左右拾音口，再说「各向内多转 10°」。示意父版均内偏 10°，子版均内偏 20°，左右方向按各自向中心计算。比较时同时给出夹座表面最大偏差、安装原点位移、姿态转角、两侧目标角前后值，并复测原来的宽度和净空等硬条件。先看叠图，再决定是否采用子版。另测两种反例：只平移夹座时形状锁可以通过、位置锁必须拦下；保持夹口宽度却改侧面轮廓时，尺寸锁可以通过、形状锁必须拦下。

## 一句新描述怎么驱动 Blender

1. **模型的工作。** 复用用户已配置的 Studio Agent，让它读取当前描述、选中版本及用户锁定的要求，调用造型工具。首次生成返回三份各自完整的操作清单，写明每个主要要求对应哪个对象或操作，哪些要求未表达。模型负责在运行时决定形状、截面数量与坐标、组合关系和参数。产品库里不放成品形状，也不按名词查外壳。首版无需训练或分发专用模型；模型服务的连接要求和计费沿用已有配置。
2. **Blender 的工作。** 在主进程探测用户的 Blender 可执行文件（macOS 支持应用包路径和手选路径），运行前确认版本/后台能力。Studio 随包提供受控 Python 驱动，启动类似 `blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python <driver> -- <job>` 的独立进程。模型交的是经过 schema 校验的数据；它可以组合操作和给出新坐标。驱动用 bpy 建真实对象、曲线、网格和修改器，保存 .blend，重开后读取最终几何，导出 GLB 和统一相机的缩略图。用已有 ModelViewer 预览 GLB。对每个操作限制输入范围、对象数和细分量；工具只接受本设计的资源标识，不接受任意脚本、文件路径或 shell 命令。第一版在 Mac 上使用用户安装的后端。[Blender 命令行](https://docs.blender.org/manual/en/4.5/advanced/command_line/arguments.html)
3. **首批造型动作。** 平面闭合轮廓用可编辑点和线段/圆弧表示，可拉伸、旋转成形；多截面可改变位置与宽高形成过渡体，还可镜像、并体/切除、加局部细分或形变。分两批交付，先通轮廓、拉伸及多截面，再接旋转、布尔与局部变形。尺寸都绑定对象和单位。这些是积木，能组成开发者从未画过的外形；超出已实现动作时，标出哪一句还没做到，允许改要求、保留局部成果或交外部 Blender 完善。
4. **三个候选的门槛。** 共用单位、基准、比例和硬条件。生成器给出不同的主轮廓、截面分布或部件布局，再从最终几何取一致视角的轮廓和关键截面比较。只换材质、视角、顺序或细小圆角的近重复候选退回重做；同一候选最多自动补一次，仍不足就显示实际数量及原因。用户明确只想比较颜色或某个圆角时按其限定比较。视觉差异与是否满足用途由用户最终选择，比较算法只筛近重复。
5. **接着改的依据。** 操作与部位使用稳定标识（如安装底面、左握持面），保存依赖关系、锁定项、版本和实际 .blend 内容摘要。后续模型提交针对父版本的增删改清单，驱动在副本上更新受影响的对象，保存新 .blend。保留未涉及对象的标识和实际几何；重算后用实测截面、坐标或尺寸核对锁定项。改动与锁冲突时展示具体冲突，让用户改要求或主动解锁。父版、其他候选与已导出的 CAD 版本都能独立打开。
6. **外部编辑。** 用户在桌面 Blender 调整后可作为新版本接回。先检查对象标识、修改器、最终几何和基准是否仍匹配。能定位的对象继续接受增量修改；丢失对应关系的区域保留为用户编辑的参照，并要求重新选取基准或在 Blender 中继续。由旧操作重放导致用户雕刻丢失时不得发布新版本。

## CAD 判断要落到所选零件

**候选卡的预测和试建结果分开。** 初看操作清单只能显示「可尝试重建」；点检查后由 FreeCAD 实跑判定。状态绑定外形版本、外形摘要、关键面、基准、容差、操作映射版本及后端版本。任一项变化使已有结论过期，可查看旧产物或重新检查。不能把斜面能重建推广为任何含斜面的产品都能抽壳。

| 试建时逐项检查 | 首版实施和结果 |
| --- | --- |
| 有无尺度、朝向、可定位的安装面，以及不可改变的部位 | 缺失先请求用户补正；所有 CAD 默认单位为 mm，对同一基准显式变换。未知尺度的导入网格仍可浏览 |
| 每项可见外形有没有已验收的 CAD 操作 | 第一批只打通封闭平面直线轮廓的直线拉伸，及满足相应前提的开口底壳、平面圆孔/柱等。检查轮廓闭合、操作依赖、开口面、交叠和边界条件。后续按实测加圆弧、旋转、放样等。Blender 支持集合始终可以更大 |
| 真正造出的外形是否和选中版本一致 | 从重开的 .blend 读取求值后的外表面，在共同基准下对照 FreeCAD 的**外形母体**。先比硬尺寸、孔轴、锁定面，再对照关键截面与全外表面双向偏差。保留最大偏差位置、采样密度/细分误差和允许值。直线截面可直接比边和端点；近阈值时加密或转人工。用户未确认工程容差前只给测量结果。新掏出的腔、用户指定的开口和结构孔单独校验 |
| 能否据此做指定结构 | 分开记录「外形可重建」和「此结构已生成」。壳体检查抽壳/切腔结果、开口、关键处壁厚、孔位和预定实体数。更改一个原生尺寸后复测依赖尺寸。写出 STEP 再读回，检查闭合、实体有效、尺寸、基准和指定结构。仅成功写文件或保持包围盒相同均不足以通过。[OCCT 几何有效性接口](https://dev.opencascade.org/doc/refman/html/class_b_rep_check___analyzer.html) |

- **整件可重建。** 所选范围内的外形与锁定特征均通过。开放工程参数；结构通过后可出这件零件的 .FCStd 与 STEP。
- **局部可重建。** 例如安装平台和孔轴通过了，侧面的捏痕或渐变曲面没有 CAD 对应。传递可编辑基准/已验证独立实体、等比外形参照和缺项清单。工程师补外皮，再验同一组偏差。依赖缺失曲面的孔位要等基准解决，不能自行猜测。
- **外形参照。** 只有自由网格或整件偏差超限且没有独立可靠区域时，保留 .blend、等比参照和关键截面。在 Blender 继续改，或让工程师据截面重建。用户随时可以回到其他候选。CAD 后端缺失、运行失败或取消单列「尚未完成检查」，可重试，不代表形状必须人工重建。

## 工程拆分与数据所有权

**先把一件从新描述做到 STEP，再把这个能力扩成三款。** 开发团队首先约定一类可验证的输入范围：由闭合直线轮廓拉伸、可从指定平面开口的单件壳，至少有一个可追改的轮廓特征和一个可锁定的基准或尺寸。适配器接运行时任意合法的顶点和尺寸；仓库不内置题目、选中模型或导出件。所举拾音器只用于解释交互，发布盲题另出。

| 实施先后 | 工程落点及前置 | 这一步在真实 Studio 里能做什么 |
| --- | --- | --- |
| 1a 现场造一款 | 在工具入口新建设计标签，接已有 Agent Run / ToolHost 和有界 Blender 进程；先实现闭合多边形及直线拉伸、稳定对象标识、几何回读与 GLB 预览 | 验收人现场给出用途、截面意图、自定尺寸；从空项目生成一份实际可重开的 .blend，点原句能量到对应几何 |
| 1b 在同一款上追改 | 选父版，保存一个锁和目标特征；同一驱动接受增量操作，读取两个版本的几何 | 临时决定改哪一段，确认锁定项和目标变化；保存子版并退出重开 |
| 1c 把刚改的子版做成实体 | 先实现与 1a 一致的 FreeCAD 原生草图/拉伸映射、开口和壁厚；接现有后端探测、写新文件确认、独立回读。基准、允许偏差和版本由用户确认 | 通过外形对照后调整壳壁，得到该子版的 .FCStd 和 STEP。独立 FreeCAD 能再改参数，重新导入 STEP 能量出内外尺寸。1a–1c 连续完成才算第一条内部闭环 |
| 2 做成三款可选、可回来的产品 | 在同一服务上增加多截面造型、三份几何输出、不同轮廓检查、逐句对照、逐款 CAD 预判，以及形状/位置/尺寸锁、分支与冲突处理 | 同一句新描述获得三款，先看对题程度和预计工程工作量，自选一款追改；关掉再开后，原款、另外两款与修改版均能找到 |
| 3 验证工程交接边界并交付 | 加入局部与参照路径，补单位错配、外部编辑、重试/恢复；按已验证范围接平面孔柱。沿用既有 CAD 截面插入工具契约 | 同一场验收，所选可重建款走到 STEP；混合形体拿到已验证部位及待补曲面；无匹配外形拿到等比参照。三款比较与持续追改均须通过才交第一版 |

设计文档在项目目录保存**选中版本、版本谱系、意图、锁定项、引用的源文件/输出及核验记录**，由新的主进程造型服务唯一写入。Workspace/Tab 继续管理项目与标签，Agent Run 管会话和工具执行生命周期，现有 CAD 服务负责 CAD 执行，界面订阅结果。路径在项目内相对引用；用户文件与可再生缩略图分开。renderer 只走有类型的 IPC，执行从真实的本地工作区取授权。接入前对应阅读 [CAD 工具模块](../../../../../src/main/mcp/modules/cad/index.ts)、[预览契约](../../../../../src/shared/ipc/cad.ts)、[3D 画布](../../../../../src/renderer/src/components/workbench/ModelViewer.tsx) 和[架构宪法](../../../../architecture.md)。

运行任务带父版本摘要与请求标识，临时目录生成并回读，成功后以新的版本名写入并原子更新文档索引；相同请求重试复用已完成结果。界面切换项目后任务仍绑定原工作区；关项目按现有生命周期取消，子进程退出后保留已发布版本。并发编辑基于同一父版可分支，选中指针更新时比较当前版本。进程崩溃/磁盘满只清理本次未发布文件；重开按文档记录恢复，已中断项可重试。未配置模型时可浏览已有设计；缺 Blender 指向安装位置并允许重新检测；缺 FreeCAD 仍可生成和追改外形。诊断记录运行标识、输入输出摘要、阶段、命令退出状态、后端版本和丢失的特征。

## 真人盲测与发布门槛

**内部首条链路与交付版分别签收。** 单款已通过真实 macOS 桌面应用的自动化操作，验收人可另出新题复测。三款交付版仍待实施。收据保存应用与后端版本、题目、产物路径和逐步结果。

1. **内部验收，一人一题走到底。** 构建完成后给验收人一张“闭合多边形、直线拉伸、可开口单件”的能力卡。验收人现场决定用途、轮廓、硬尺寸和一个需要保留的部位，开发者不供成品；用空目录、禁用生成结果缓存。① 输入原句，重开该次 .blend 并量一项硬尺寸。② 验收人现场指定第二句话，锁一处改另一处；同视角核对实测并接受子版。③ 退出重开，选择这个子版，确认开口面、坐标和允许偏差，在 FreeCAD 试建，核对独有的追改特征和外形。④ 定义壁厚/底厚，修改壁厚，另存 .FCStd 和 STEP。⑤ 在独立 FreeCAD 重开源文件再改一项参数，另开空白文档导入刚导出的 STEP。定位同一截面，量外宽、内宽及第②步改过的特征，核对闭合有效实体数。任一步切换成开发者准备的文件、用父版导出或没有回读，都记该步失败。保留原话、运行标识、父子版摘要、源和交换件、测量位置与数值。
2. **交付验收，真实选款后走同一条链。** 验收人临场出两道不同用途的题，一道「需要接着出 STEP」，处于已支持几何范围；另一道「优先探索外形」，含自由形态要求。逐款点原句，截图标出对应部位、实测尺寸和缺项；在选择前记录每款预计可转的零件和需人工的区域。三款各自可旋转、可在 Blender 重开，验收人能说明实际造型差异。对第一题，用户自行从符合条件的候选中选一款，追改、退出重开、做结构、回读 STEP 全程使用这款的子版，不允许在 CAD 步骤换成另一件。对第二题，分别比较预计和实跑理由；如选中自由曲面，可正常继续 Blender 修改和交接。候选少于三款时界面须如实显示，成功生成三款这一验收项记为未通过。
3. **追改与尺寸反验。** 验收人指定形状锁、位置锁、尺寸锁，按前述两种反例检查能否分别拦截；故意提出与锁冲突的修改，确认父版和另两款不变。工程测量选择两侧平行直壁的固定截面、保持外宽并向内增厚，左右各增加 1 mm 时内宽应减少 2 mm，只改一侧 1 mm 时内宽应减少 1 mm；其中对称改参为首条闭环必测，单侧算例用于支持独立改壁时的验收。源文件可改性、STEP 的读回结果、后续实物试装分别记录。
4. **能识别局部和失败。** 输入混合几何（已知基准加自由曲面）、纯自由形体各一例；分别得到局部交接和外形参照。另对一个已通过的 .blend 在 Blender 手工做局部凹陷，保持外包尺寸不变。原结论必须过期；重检应点出未匹配区域。把单位改错、让腔体厚到消失，也要各自得到可修复原因。失败后仍能打开先前的设计和产物。
5. **能在实际项目里回来。** 在生成中取消、关闭项目、重启 Studio；缺模型、缺 Blender、缺 FreeCAD 分别复测。最后在通用项目和电子开发项目分别打开设计，确认侧栏和项目类型保留，选中版本随设计走。验收记录分开列「几何与文件回读」「真人选择/追改」「实体打样」；前两项通过只支持软件设计闭环，打样与生产另按产品实物验收。
