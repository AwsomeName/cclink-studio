## 早期五步交互原型

**早期原型验证动作**　在 Studio 的本地工程描述一个圆角直壁设备底壳，从两个 Blender 外形中选定一款，核对尺寸和基准，进入 FreeCAD 修改壁厚，导出新 STEP 并重新打开。外形尺寸和孔位保持不变，内腔随壁厚改变。用户获得选中外形的 .blend、可编辑的 .FCStd 和交换用 STEP。这个目标可用于传感器、控制器、小仪表等产品，这一轮原型只验证一种几何模板。

| --- | --- | --- | --- |
| 描述外形 | 写用途和限制，确认尺寸单位 | Agent 将描述转为受约束的外形参数，缺尺寸先补充；超出模板说明原因 | 本地工程和 Agent 会话 |

| 转入 CAD | 确认底面中心、朝上方向、单位和不能动的尺寸 | 将选定的长宽高、圆角、坐标系与外形参照传给 FreeCAD，按同一组参数重建。核对平面轮廓、关键截面、圆角和高度。错误或偏差超限时停止 | 本地 FreeCADCmd 探测和执行能力 |
| 改结构 | 调整壁厚，核对底厚与安装柱 | 在 CAD 文件中重算内腔和安装柱，检查最小剩余空间、导孔位置、壁厚与几何有效性 | 既有 CAD 服务生命周期和核验模式 |
| 导出 STEP | 确认版本、文件名和范围 | 接入模板工程导出、发布后回读、结果卡；源文件与 STEP 各自保留 | 受限截面插入已有独占写入新 STEP、回读核验和自动打开能力 |

**交接依据。** Blender 与 FreeCAD 共用经过确认的参数。Blender 保存所选外形，CAD 保存工程结构。一方改变后，保留旧文件，原交接标为需重新核对。只有三角网格、经过自由雕刻或不符合模板时，先保留外形参考，用户可选择回到模板或人工在 CAD 中建曲面。首版只向受控程序传参数。用户确认写出前，不覆盖既有文件。

**示意已验证的部分。** 浏览器不连接模型、Blender 或 FreeCAD。两款外形的图来自同一家族的预计算几何，用于演示选择。样例覆盖圆角 6/14 mm、壁厚 2/3 mm 的四种组合。每个 STEP 均由本机 FreeCAD 导出、重新导入，确认 1 个封闭有效实体、BOP 检查通过，外廓 90 × 60 × 26 mm。独立截线读得内宽分别为 56/54 mm；四个安装柱的导孔均为空且孔外有实体材料。页面下载对应配置的真实样例 STEP；示意不生成 .blend 或 .FCStd。已点通单位错误拦截、修改壁厚、切换外形后重新确认及浏览器下载。

**真实产品验收仍待实施。** 从空工程走五步，修改描述后确有新 Blender 方案；离开再打开仍能找到选定 .blend；CAD 源能重开和改参；变更壁厚后导出新名，回读外廓、内宽与柱位，保留旧版；缺一个后端、单位错配或取消时能说明原因、回到可操作的上一步。[当前仓库 STEP 验收记录](../../../../features/eyewear-step-ai-editing-development-plan.md)

## 换描述以后怎么造型，选中后如何分流

[本机 Blender 外形与 CAD 实物文件](shape-cases/index.html) · [两款渲染对照](shape-cases/comparison.png)

**生成。** 拟议的 Studio 先把用途和风格词解释成可核对的造型动作。比如“操作面朝向我”落实为前后高度不同的侧截面，“前窄后宽、拇指留窝”落实为沿长度改变的截面和局部压陷。用户给的是设计意图，未给的尺寸、方向和固定部位明确标为假设。将动作和参数交给受控的 Blender 适配器，保留可继续编辑的对象或修改器，运行后从文件读回尺寸，再出候选图。无法表达的要求应保留并说明，不悄悄换成预设圆角。

**交给 CAD。** 判定依据是所选版本保留的参数、基准及建模操作是否有已实现的 CAD 对应操作，并经实际重建验证。对手工改过的 .blend 还要比对求值后的几何，规则名称或旧参数本身不能证明一致。

| 状态 | 交付与动作 |
| --- | --- |
| 自动重建 | 对已支持的参数特征重建，检查单位、朝向、关键截面/表面偏差、封闭实体及壁厚等；通过后方可继续改工程结构。预生成圆角底壳和本轮原生侧断面斜台分别已有样例；不代表任意拉伸、倒圆、扫掠已经受支持。 |
| 部分重建 | 已知孔轴、安装面和基准等可单独保留，未映射的外皮作为参照。需要工程师补曲面，再比较新外皮。首版界面应列出逐项清单，不能让局部成功把整件标成可导出。 |
| 参照／人工重建 | 只有细分、雕刻、扫描网格，或自动重建后出现曲面偏差超限、自交、抽壳失败时，可先看外形。若需要可改结构的工程实体，结构人员根据截面与边界拟合或重设计，并确认配合面、最薄处及偏差。已获得可靠的原生实体时可直接使用，避免重复重建。 |

**2026-11-27 本机实测。** 两条输入由本会话的 AI 写成建模操作，调用隔离环境中的 Blender 官方 Python 模块 4.5.3 LTS，保存 .blend、重新打开并渲染。斜台样例从重新打开的 Blender 外形读取 8 个顶点，在 FreeCAD 1.1.4 中重建受尺寸约束的侧断面，核对重建外形的 8 个顶点，得到开口底壳。修改壁厚 2→3 mm 后内宽 86→84 mm，改回后导出，STEP 回读为 1 个封闭有效实体，90 × 60 × 36 mm，BOP 检查通过；.FCStd 重开成功。遥控器 .blend 重开后保留 Thumb recess 形态键及细分修改器。浏览器提供这些实测文件；任意新文字自动驱动模型与 Blender 的正式 Studio 入口仍待开发。
