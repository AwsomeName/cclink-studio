## 实现边界

- WebAffair 仍是唯一状态所有者。CSDN 授权绑定原 Attempt、执行代次、旧未知副作用与 draftId；保留旧未知记录。仅一次额外提交，已经派发后不能携带授权重新发送。
- 原草稿恢复重新核验账号、标题、正文、三图和保存状态。禁止新建原稿、重写正文、重传图片；真实发现分类未随草稿重开保留后，仅允许当前 inspect 证明分类为空时恢复冻结分类及保存。其他字段不匹配仍停止。
- 尚未派发的续发授权可随同一 Attempt 的暂停/中断恢复进入新代次。原账号、稿件或已派发状态改变时不携带。
- 微博原生回执超时时，只查找同账号当前页面中逐图身份和顺序完全相同的唯一作品；重复请求、回执内容冲突不能走此分支。头条收到唯一成功提交并匹配管理页后，由 Studio 打开已发布的对应作品。
- 结果定位仍在同一长 Run 内，沿 BrowserManager 与已有 Runtime 收敛链路导航。取消、失效代次、错账号、多候选、审核中、全文或图片不符都停止；不会启动额外任务、后台重发或修改持久文件绕过保护。
- 找到链接不是完成。main 必须核验公开账号、冻结全文及原图；Agent 仍经现有检查点完成公开核验。
