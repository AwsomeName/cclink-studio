## 用户功能进度

用户现在可以在公司项目里：

- 打开**项目首页**，看到“今天要处理”：等你回复的售后与意向客户（按等待时长）、待核对流水、需重新登录的网站账号、等你处理或结果未知的发布任务、缺目标或关联资料出问题的业务。每条都直达原处理页面。
- 看本月**已确认收支**、按业务的支出，以及单列、不计入的待核对金额；在首页直接**确认**待核对流水（规则与公司账目相同，缺凭证或字段时提示去核对）。
- 在左侧“公司经营”进入**推广**：列出项目里全部文章发布任务（等你处理 / 其余），新建文章发布，查看发布账号登录状态并打开账号页面登录。
- 进入**客户与售后**：手动记一条售后或意向客户，按“等你 / 售后 / 意向 / 等对方 / 已解决”筛选，标记“已回复，等对方”“对方回复了”“已解决”。等你回复的记录进入首页待办，回复后离开。

用户还不能：自动读取网店订单、售后单、评论或私信（取决于网店平台，待定）；让 Agent 起草回复；使用经营决策卡、产品事实表和自建待办（本版按用户要求推迟）。首页收支只来自公司账目，不含网店订单数。

## 真人可执行步骤

1. 新建或打开一个类型为“公司”的项目，在项目首页填写公司名称并“开始使用”。预期：左侧“公司经营”下有 业务项目 / 推广 / 客户与售后 / 公司账目。
2. 点“客户与售后”→“记一条”，填写客户、来源、订单号和问题，保存。回到“项目首页”。预期：今天要处理出现“回复 1 个售后问题”，显示等待时长。
3. 点“去处理售后”，在记录上点“已回复，等对方”。回到首页。预期：该待办消失；客户与售后“等对方”计数为 1。
4. 在公司账目导入一个月份的流水但不确认，首页选择同一月份。预期：待核对流水列出最多 5 条，收支卡显示“另有 N 条待核对，未计入”；点“确认”，已确认收支随之变化，或提示去核对补全。
5. 点“推广”。预期：列出项目里已有文章发布任务，“打开发布任务”打开原任务；“新建文章发布”打开原发布流程；账号行显示与“设置 · 网站与账号”相同的登录状态。
6. 完整重启 Studio，回到项目首页。预期：客户记录、业务与账目归属保留。

## 已知限制

- 客户记录需要手动录入；保存在公司项目 `.cclink-studio/company-workspace/company.sqlite`，与业务数据同处，不上传、不进诊断。Studio 不会自动把 `.cclink-studio` 加入 `.gitignore`：如果公司项目本身是 Git 仓库，提交前需排除该目录（公司账目同样如此）。
