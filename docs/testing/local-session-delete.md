# 本地已关闭会话删除验收

## 用户验收动作

1. 在本地项目准备两条可丢弃的会话，关闭后展开「已关闭」。保留一条其他历史作为对照。
2. 点击删除后取消：会话应保留。
3. 连续确认删除两条测试会话：对应条目消失，写盘确认后提示「会话已删除」。
4. 切换到其他项目再切回，并退出、重启 Studio：两条会话不应恢复，对照历史应保留。
5. 在隔离测试中注入保存失败：被删条目应恢复，显示具体失败原因，不得提示成功。

## 修复范围

WorkspaceState renderer 写队列原来同时合并快照及 options。写盘未完成时，后续普通
保存或另一条删除可以覆盖 `conversationHistoryMutation`，造成显式删除没有送达主进程，
但调用方收到成功。主进程的历史保护随后会保留本应删除的记录。

现在显式删除及清空消息分别串行落盘，只有相邻普通快照继续合并；未取消历史保护。
删除持久化失败时恢复条目并提示错误；恢复事务期间拒绝删除，防止写入被跳过。
框架日志记录 `delete-requested`、`delete-saved`、`delete-failed` 及会话 ID，不记录正文。
会话状态仍由现有 Agent store / WorkspaceState 链路拥有；不增加 IPC 或权限面。
