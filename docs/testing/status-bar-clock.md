# 底栏日期与时间验收

## 用户可执行验收

1. 启动 `pnpm dev`，打开本地工作空间，查看底栏正中。
   - 宽窗口显示 `YYYY/MM/DD 周X · HH:mm`，位置以整个窗口为中心。
   - 不显示秒，保持原有 22px 底栏与 12px 字号。
2. 缩窄窗口至约 900px，再缩至约 640px，然后恢复宽窗口。
   - 依次使用完整、紧凑 `MM/DD · HH:mm` 格式；居中位置不随左右信息长度移动。
   - 长分支、工作空间名、网址、更新提示和版本文字不会侵入时钟。
   - 更窄时收起网址、版本与日志按钮文字；Git 和更新操作仍可使用。
3. 悬停或键盘聚焦时钟，核对完整日期、星期和本机时区；等待下一分钟。
   - 时间与本机一致，分钟到点更新。应用重新获得焦点后重新读取本机时间。
4. 打开 Git 状态和更新面板，然后关闭。
   - 弹层未被左右分组裁剪，操作入口仍有效。
5. 触发一条底栏提示。
   - 提示仅临时替换中央时钟，不覆盖左右内容；结束后时钟恢复。
   - 完整提示仍可悬停查看。提示保持在底栏内，不进入原生浏览器视图区域。

## 边界

- 仅由 `StatusBarClock` 持有本机时间的展示快照，无持久化、网络或新增 IPC/权限。
- 每次定时回调重新读取系统时间并对齐下一分钟；focus、pageshow、可见性恢复时立即刷新。
- 卸载时清理计时器及监听器。时间来源为本机系统，系统时间错误会如实反映。
- 底栏使用等宽左右列和独立中央列。容器内容宽度 ≤1100px 使用紧凑格式，≤760px 收起次要文字；窗口含两侧共 24px 内边距。
- 收起或截断内容保留原有 title、可访问名称及操作入口，不新增右键菜单。
