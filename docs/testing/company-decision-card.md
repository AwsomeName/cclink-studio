# 公司首页 · 经营决策卡真人验收

对应 [ADR 0025](../decisions/0025-company-decision-records.md) 与[效果稿](../design/company-home-decision-2026-11-22/README.md)。需要一台已能运行本地 Agent（Codex 或 Claude Code）的 Mac，以及一个已启用公司视图的工作空间。

## 步骤与通过标准

| #   | 操作                                                                                                  | 通过标准                                                                                                   |
| --- | ----------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 1   | 打开“我的公司”首页                                                                                    | 最上方是“经营决策”卡，右上角有“帮我想清楚一个问题”；下面仍是今天要处理、收支、待核对、业务项目、推广与客户 |
| 2   | 点“帮我想清楚一个问题”，写“AR 眼镜一代首批先卖给谁，怎么定价？”，补充“首批 300 台，零件约每台 600 元” | 资料范围默认勾选账目汇总、推广与客户记录、业务项目，网上公开资料不勾                                       |
| 3   | 点“交给 Owner”                                                                                        | 卡片显示“Owner 正在读资料并思考”；“打开 Owner 会话”能在右侧 Agent 面板看到这次委托                         |
| 4   | 等待结果                                                                                              | 出现追问（可点选项或自己写）或直接出现建议；追问最多两轮                                                   |
| 5   | 回答追问并点“回答并继续”                                                                              | 回到思考中，随后出现：一句建议、2–4 个方案（推荐项有标记）、依据（标来源与估算）、重想条件                 |
| 6   | 选另一个方案，点“改一下再采纳”，改写后采纳                                                            | 卡片显示“已记为决策”和日期；给出推广产品、跟进客户、售后服务三个入口；账目、客户记录不变                   |
| 7   | 退出并重新打开 Studio                                                                                 | 决策仍在“最近的决策”中，状态已采纳；没有新的 Owner 运行                                                    |
| 8   | 在思考进行中关闭 Studio 再打开                                                                        | 卡片按原运行对账：完成则显示结果，找不到运行则显示原因与“重新思考”，不自动重派                             |
| 9   | 停用本地 Agent（或断网）后再交办                                                                      | 卡片显示失败原因和“重新思考”，首页其他部分正常                                                             |

## 2026-11-22 自动化走查（真实 Electron + 本机 Codex）

`node scripts/company-decision-smoke.mjs`（需先 `pnpm build`）。7 项全部通过，[结果](company-decision-card/result.json)：

- 首页最上方显示经营决策卡，其他区块保留（[首页](company-decision-card/01-home.png)、[交办](company-decision-card/02-ask.png)）。
- 交办后记录运行（[思考中](company-decision-card/03-thinking.png)）；Owner 真实追问两轮，第一轮点选项、第二轮手写回答（[追问](company-decision-card/04-clarify-1.png)）。

- 选非推荐方案并改写后采纳；账目、客户、业务和关联前后一致；出现推广产品、跟进客户、售后服务入口（[已采纳](company-decision-card/06-adopted.png)）。

走查中发现并修复：首次运行中 Owner 的建议因格式严格校验被拒且原因不明；现改为忽略多余字段、允许空的可选项、放宽长度，并在卡片上写明出错字段。`pnpm verify` 通过（483 个测试文件，4157 项）。另重跑 `scripts/company-workspace-smoke.mjs` 13 项全部通过。

脚本的回答是机械的，不代表真实经营判断。上表第 8、9 步（思考中退出重开、Agent 不可用）以及真人按自己业务实际走一遍，仍待验收。
