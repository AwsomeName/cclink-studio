# 浏览器工具栏与新建入口验收

2026-11-10，macOS / Electron 43 开发版。

## 用户验收动作

1. 在工作台右上角分别点击「浏览器」「MD」「Terminal」，应直接创建对应标签；会话仍从会话区创建。
2. 在浏览器地址栏输入 `192.168.31.1`，应使用 HTTP 打开小米路由器管理页。明确输入的 HTTPS 地址保持原协议。
3. 点击「保存账号」，命名表单应在工具栏下方展开、网页向下让位。取消或 Escape 应关闭表单并将焦点返回按钮。
4. 点击「更多浏览器操作」，应能访问缩放、适应宽度、设备模式、浏览历史和当前登录环境。仅在编辑过百分比后，按 Enter 或移开焦点才提交；只查看选项不得关闭自动适宽。按 Escape 丢弃未提交值。历史弹层中的 Escape 只关闭历史，保留显示选项。
5. 展开右侧 Agent 或缩窄窗口：新建入口收为带提示的图标；地址栏保留输入空间；被折叠的前进、缩放操作可从更多操作访问。若展开期间缩窄窗口，使原触发按钮隐藏，Escape 应将焦点返回可见的「更多浏览器操作」。
6. 打开多个标签：新建入口固定在右侧；标签可横向滚动；切换后当前标签自动进入视野；键盘 Home / End / 左右方向键可切换。浏览器状态刷新不得把用户手动滚动的位置拉回。

## 已观察的结果

- 真实用户开发实例：小米路由器登录页正常显示；展开 Agent 后约 530px 宽工作区的新建入口、地址栏、保存与显示选项可操作；关闭展开区后网页恢复布局。没有提交路由器登录或保存其凭证。
- 独立 Electron 实例：使用独立用户数据与本地 HTTP 登录标记夹具，三个新建按钮、Terminal 真实进程与重启通过；账号原位保存、跨工作空间复用与应用重启后的登录状态保留通过。
- 布局自动化使用 renderer 视口尺寸模拟，读主进程原生 View 诊断确认顶部边界。它不等同于把系统窗口物理缩到相同尺寸。

| Renderer 视口宽度 | 工作区实际宽度 | 地址输入区宽度 | 创建入口   |
| ----------------- | -------------- | -------------- | ---------- |
| 1440px            | 1056px         | 约 615px       | 图标与文字 |
| 1000px            | 616px          | 约 330px       | 图标       |
| 760px             | 376px          | 约 202px       | 图标       |

17 个真实标签下，新建入口位置固定、溢出滚动与键盘切换通过。各宽度保存表单展开后，原生网页顶部均位于工具栏与表单下方；未侵入标签栏。历史弹层显示时原生网页按既有浮层机制隐藏，关闭后恢复。

## 边界

BrowserManager 仍独占原生网页 bounds、缩放、Profile 与生命周期；此次只调整展示和调用入口。三个新建动作通过现有 command registry 执行，Terminal 新建迁入同一命令源。会话 owner、IPC、权限以及自动适宽测量与阈值未改变。辅助浏览器窗口仍使用自身已有导航布局。

本轮结论限于 macOS 开发版及本地登录夹具；未做 Windows/Linux 原生窗口验证，也未发布安装包。真实第三方站点的登录有效性由站点自身决定。

## 2026-11-10 自查修复

新增真实 Electron 回归动作发现并复现了两项问题：

1. 点击缩放摘要会自动聚焦百分比输入；即使未编辑，关闭选项时的 blur 仍提交同一数值，使自动适宽变成手动。修复为只提交用户实际编辑过的输入；不改变主进程缩放算法。
2. 选项展开后缩窄窗口，原摘要按钮隐藏；Escape 尝试聚焦隐藏按钮，导致键盘焦点丢失。修复为回到仍可见的原触发按钮，原按钮隐藏时回到「更多」。

同一真实 Electron 场景在修复前返回 `unchangedZoomModes: [manual, manual, manual, manual, manual]`、`restoredVisibleFocus: false`；修复后返回五次 `fit`、`true`。两个断言已纳入工具栏 smoke，输出证据 `expansion-review.json`。
