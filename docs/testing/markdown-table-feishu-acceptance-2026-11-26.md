> 设计：`docs/design/markdown-table-feishu-2026-11-25/mockup.html`（按推荐方案确认：D1 不做列宽、
> D2 Enter 跳下一格、排序与 Excel 粘贴放第二步、D4 日记页同一套实现）。
> 方式：`scripts/markdown-table-acceptance.mjs` 启动真实 Electron，隔离 home、userData 与工作区，
> 使用模拟文档；不需要模型或账号。
> 结论：T1-T8 全部通过；同一构建上复跑 A1-A9 仍全部通过。

## 用户现在能做什么

- 鼠标移到表格上：每列顶部出现列手柄，所在行左侧出现行手柄，右侧有“+”追加列，底部有“新增一行”；移开后全部隐藏。
- 鼠标靠近行/列分隔线（左侧或顶部）出现蓝色“+”和引导线，点一下在该处插入一行/一列。
- 点列手柄：选中整列并弹出列菜单（左右插入、左/中/右对齐、左移/右移、清空此列、删除列、删除表格）。
  对齐写入分隔行 `:---` / `:---:` / `---:`。
- 点行手柄：选中整行并弹出行菜单（上下插入、复制此行到下方、上移/下移、清空此行、删除行）。
  表头行的插入上方、复制、移动、删除行置灰并说明原因。
- 拖动行/列手柄调整顺序，蓝线指示落点，⌘Z 可撤回；表头始终在第一行。⌥↑/⌥↓ 移动光标所在行。
- 框选单元格后浮条提供 复制 / 剪切 / 清空内容 / 添加到会话；复制同时写入制表符文本和 HTML 表格；
  ⌫ 只清空选中格。选中整行 ⌫ 删行，选中整列 ⌫ 删列。
- Enter 跳到下方单元格，最后一行 Enter 新增一行；⇧Enter 回到上一格；↑↓ 跨格移动。
- 列宽不可拖动（Markdown 存不下，避免“拖了不保存”的假象）。
- “我的空间”日记、计划页使用同一个 `MarkdownEditor`，交互一致（未单独自动化验收，见残余风险）。

## 本轮修复的既有问题

- 富文本保存会丢掉文件末尾换行（序列化器从不输出末尾换行，此前也无保留逻辑），导致保存后最后一行被改写。
  `normalizeMarkdownEditorOutput` 现按磁盘原文保留末尾换行。A1-A9 复跑通过。

## 残余风险

1. 日记/计划页嵌入编辑器与普通 Tab 共用组件，但本轮自动化只覆盖普通 Markdown Tab。
2. 菜单中的对齐项是 `menuitemcheckbox`，当前菜单样式不显示勾选标记，只能从表格显示判断当前对齐。
3. 按列排序、从飞书/Excel 粘贴区域（自动扩行列）属于第二步，尚未实现；当前粘贴走 prosemirror-tables 默认行为。
4. 单元格含图片时列宽由内容撑开（另一会话在评估缩略图方案）。
