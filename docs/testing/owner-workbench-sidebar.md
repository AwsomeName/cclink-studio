# Owner v2 · Ibex 真人验收

2026-11-21。验证同一个 Studio 窗口内的 Owner 工作台：左侧固定侧栏、中间事务看板与文档标签、右侧本事务 Owner 主对话。

## 本轮范围

- 用户可验：顶栏进入 Owner；事务内左侧 208 px 固定侧栏依次显示「‹ 我的事务」、事务标题、事务进度、本事务可读目录、已落地文档和事务保存位置；中间「事务进度」看板与文档标签；右侧主对话始终可见。
- 参考目录：从侧栏「配置参考目录…」用系统目录选择器授权，只读、仅本事务可见，可展开浏览、在中间预览文本文件，可撤销；重启后保留。
- 不在本轮：Owner／A 取证尚不读取本地参考目录（仍只查公开 GitHub 仓库）；授权尚未写入 `事务配置.md`；没有全局目录登记和默认父目录设置；文档标签不跨重启恢复。

## 真人操作步骤

前置：Agent 后端可用、可访问 GitHub；建议先关闭其他 Studio 实例。

0. **入口与设置（新 profile 或尚无事务）。** 点顶栏「◈ Owner」。
   - 期望：左侧固定栏显示「我的事务 · 还没有事务」「＋ 交办新事务」「⚙ Owner 设置」；中间「交给 Owner 一件事」、保存位置回显和三步说明；没有右侧聊天框。
   - 点「⚙ Owner 设置」→ 新事务保存位置「更改…」选一个文件夹；常用参考目录「＋ 登记目录…」选一个文件夹，显示「已登记 · 未授权」。回到「交办新事务」，保存位置回显为刚选的文件夹。
1. 启动 Studio（`pnpm dev`，或已安装版本）。不打开任何项目，点顶栏右上「◈ Owner」。
   - 期望：主工作台被 Owner 取代，同一窗口；列表右侧是交办框。
2. 在中间交办框输入：`开源芯片 Ibex 调研。请交付一张中文《Ibex 源码入门卡》，用这个标题。先从项目定位和默认流水线各级职责中选出适合初读的一级，再沿你选的级追到一处真实寄存器，用 RTL 中的更新条件和赋值解释它何时更新。`，点「交给 Owner」。
   - 期望：立即进入事务；左侧固定侧栏出现，宽度不随窗口变化，无拖拽手柄；「已落地文档」列出 `事务.md`、`事务配置.md`、`调度.md`、`工作记录.md`。
3. 等中间出现「调研约定 · 待你确认」卡片（顶栏显示「◈ Owner · 1 等你」；返回列表可见「等我确认」分组）。点侧栏 `事务配置.md`。
   - 期望：中间新开标签显示「待确认草案」，右侧主对话不变。点标签上的 × 关闭，回到「事务进度」。
4. 点侧栏 `调度.md`，保留该标签，点约定卡上的「确认约定，开始」（或右侧同名确认按钮）。回到「事务进度」：三枚状态分别显示事务、Owner 当前动作、执行会话 A 的真实运行；「当前步骤」写明负责人、为什么和本轮查找。
   - 期望：调度标签内容随修订刷新为「首次委派 A」。全程只需这一次确认。
5. 在右侧输入「为什么选择这些资料？目前还有哪些结论需要核对？」并发送；点「‹ 我的事务」回列表，再点回该事务。
   - 期望：同一事务、同一主对话，答复出现在原问题下。
6. 等看板显示已交付。侧栏「已落地文档」出现 `资料/`（带份数）和展开的 `交付物/`；看板绿色「交付物」卡写明引用核对数、证据快照数、文件已核验，有「打开交付物」「打开事务目录」。
7. 点「打开交付物」（或侧栏 `交付物/` 下的文件），在入门卡中点任一 RTL 引用旁的「本地证据」。
   - 期望：中间新开证据标签，滚动到并高亮对应行；右侧仍是「Owner 主对话」，输入框可用。点「返回报告」回到入门卡标签。
8. 在侧栏点「配置参考目录…」：有登记目录时先在弹窗里选它（或「选择其他目录…」走系统对话框）；随后确认弹窗写明准确路径、文件数、只授权给本事务、会发生与不会发生，点「允许本事务只读」。
   - 期望：取消则什么都不授权；确认后目录出现在「本事务可读目录」下，可展开子目录；点文本文件在中间只读预览（Markdown 渲染，其它文本带行号）。选择包含事务目录的上级目录会被拒绝。
9. 点「‹ 我的事务」→「＋ 交办新事务」另发一件（或打开已有的另一件）。
   - 期望：另一件事务的「本事务可读目录」为空，看不到第 8 步授权的目录。
10. 退出 Studio 再启动，进 Owner、点回 Ibex 事务。
    - 期望：参考目录授权仍在；看板、主对话答复和交付物保持。点目录右侧 × 撤销后不再列出，已打开的该目录标签随之关闭。
11. 在任一事务看板标题行右侧点「⧉ 复制 Owner 诊断」。
    - 期望：按钮变为「✓ 已复制」，弹出说明列出包含 / 不包含的内容，可「查看全文」；粘贴出的文本以「# Owner 诊断」开头，有事务 ID、三种状态、每次派工的运行 ID 与终态、执行记录和相关框架日志，没有聊天正文、证据原文，路径中的用户名显示为 ~。事务处于待保存 / 需要处理 / 待恢复时，问题卡片里的同名按钮复制同一份。
12. 点「◈ Owner」或顶栏其他按钮退出 Owner。
    - 期望：恢复原工作台及原标签选择。
