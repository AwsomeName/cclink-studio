## 用户功能进度

我的空间已提供今天、日记、计划、定时整理、资料接入与 Git 侧栏。首页直接预览原 Markdown 已保存正文，继续写打开同一个原文件；首次使用可从空白日记开始。每日简报与每周计划按原工作空间和原任务 ID 关联，不复制、自动启用或改写原定义。

准备今天可以离线创建未知事实留空的四段模板，按确认的时区与年/月目录命名；重复操作使用已有文件。已关联每日任务的输出路径匹配今日日记时可调用原 runNow，状态、错误和产物继续由原任务服务拥有；路径不匹配时明确提示用户在原任务中核对，不自动改定义。定时输出目录新增 `{year}/{month}/{day}` 日期变量，旧静态目录保持原含义。

Git 已提供新目录 Clone、已有仓库检查、Fetch、文件清单与正文差异、未提交内容/历史分叉/过期预览拦截、已审阅版本下载到新副本，以及显式确认后切换个人资料来源。**更新始终另建副本，不在旧目录执行 Pull、reset、stash 或覆盖工作文件。** 整仓变更、提交和上传复用原 Git 界面。HTTPS Token 仅用于本次操作；SSH 要求明确私钥及已有主机信任，不调用系统钥匙串。副本生成位置固定在用户目录的 `CCLinkStudio-Git/diary-*/repository`。

用户确认原资料只在另一台电脑，授权简单模拟。本次没有读取另一台电脑的原件，未使用用户 Git 服务器或模型账号。没有打包、发布或替换正式安装的应用。

## 真人可执行验收

1. 打开原 woniu-forward，然后进入固定“我的空间”。在“资料接入”选择原根目录与 `000-个人计划`，确认时区。首页应显示原今日正文；“日记”和“计划”可选择原文件预览，继续写进入原空间的同一路径编辑器。
2. 在“定时整理”勾选原每日简报和每周计划并保存。打开原任务与历史，核对原指令、计划、启用和 ID；连接本身不执行任务。换机时检查原指令中的电脑绝对路径。
3. 对尚无今日日记的模拟目录点击“创建今日空白模板”。检查年/月目录与四段正文；未知信息为空。再次准备应复用同一文件。已有日记直接继续写。
4. Git 页填仓库地址、分支和需要的本次认证，点击“从 Git 拉取到新目录”。成功后显示新目录，尚不切换来源；核对个人子目录及旧任务提示，勾选确认后改用该副本。
5. 在远程增加提交后点“检查远程更新”。应看见新增/修改/删除和正文 Diff，当前副本文件与 HEAD 不变。添加本地未提交文件时，更新按钮禁用；直接调用主进程也返回失败原因。
6. 工作目录干净且历史可快进时，把已审阅更新拉取为新副本并确认连接。首页显示新正文，前一个副本仍保留原字节与 HEAD。旧目录的私有任务和未上传资料不会自动跟来；新副本的共享定义不自动启用。
7. 完全退出、重启并点击“我的空间”，确认正文和已确认来源恢复。比较接入前后的原日记、计划、附件和任务定义，字节相同。

## 验证边界与残余风险

- 私有 HTTPS/SSH 服务器的成功登录、加密 SSH 私钥交互及真实模型生成未使用用户账号验证；本轮 Git 传输用真实本地远程验证，AI 生成依赖原运行器，成功/失败模板和创建保护由受影响运行器测试覆盖。空白模板不冒充 AI 生成结果。
- 原位旧目录接回与跨设备 Git 副本是两条路径。Git 只携带已提交文件和显式共享定义；原机的私有任务、历史、本机启用、凭证和未上传资料不可能由 Clone 自动恢复。
- 本轮按“不覆盖原文件”把原地快进改为新副本更新；没有交付原地合并、自动同步或多设备单次执行保证。旧任务不会因切换来源自动暂停，页面已明确提示。
- 来源按一份个人资料目录聚合，支持截图的年/月、周计划及项目记录结构；多库聚合和逐用途独立映射不在当前实现范围。超大目录/正文有明确读取上限并保留原文入口。
