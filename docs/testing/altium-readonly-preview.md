可人工复现的步骤：

1. 启动当前源码开发版，打开 `生产/20260210_pcb_原理图/`。
2. 在文件树点击上述 3 张原理图及 PCB，确认显示图形而非文本。
3. 在画布上滚轮放大、按住鼠标左键拖动，再点击“适合窗口”。已验证按钮缩放 100% → 125% → 100%，以及滚轮放大音频区域至约 306%。
4. 打开 PCB，分别选择 TOP、BOTTOM、MID2；确认图像发生变化。平移后可恢复适合窗口。
5. 打开工程文件，点击 `power_audio.SchDoc` 对应的“查看图纸”，回到原理图。缺失引用不能点击。
6. 开启“显示隐藏文字”，可见源文件隐藏的 U6 / EA3059C。关闭后恢复原稿隐藏规则；开启可能造成隐藏参数文字叠加。
7. 损坏文件显示“无法预览文件”、错误原因、重新加载和系统打开按钮；切换回原工作区仍正常显示。

## 重启后的逐图自查

在日常使用的开发版工作台中执行 `bash scripts/restart.sh restart`，从 `cclink-studio` 项目文件树展开实际目录，逐个打开全部五个文件、截图并查看画面；修复后再次重启并逐张复验。原有文件标签和工程入口可恢复。最后保留工作台在 `LCD.PcbDoc` 的 TOP 层。

本轮发现并修复：

| 问题 | 修复及实际复验 |
| --- | --- |
| 滚轮缩放触发 passive event listener 错误 | 使用可阻止默认行为的原生 wheel 监听，并在卸载时清理；306% 放大、横向滚动不误缩放通过，最终 renderer 控制台错误为 0 |
| 刚切换隐藏文字就打开其他图纸，可能显示“预览忙” | 两个 Worker 上限保留，增加有界排队；连续切图及返回前面的图纸通过，无需手动重试；另测队列、内存上限、超时和进程失败后的恢复 |
| 四个 PCB 尺寸均误显示成 `10mil`，部分文字压住箭头 | 原因是固定版解析库把 `TEXTFORMAT` 直接作为文字，并按参考点斜距处理线性尺寸；改为按尺寸轴投影及源单位计算，自动文字居中。实际样本显示 16.76、9.91、46.09、19.95（源单位 mm），截图确认箭头和文字可辨 |
| 图层列表中同层别名重复 | 使用与渲染一致的层栈映射；`MID2` / `MIDLAYER2` 和 `PLANE1` / `INTERNALPLANE1` 不再重复；TOP、BOTTOM、MID2 画面逐张核对 |

线性尺寸字段语义参考 [KiCad 的 Altium 线性尺寸导入实现](https://docs.kicad.org/doxygen/altium__pcb_8cpp_source.html)。本轮是源数据、实际渲染和交互核验，仍未与原生 Altium 逐图元比对，不能据此声明制造尺寸认证。
