# Studio 自主任务自动选择 Agent

日期：2026-11-11。决策：[ADR 0023](../decisions/0023-automatic-task-agent-selection.md)。

## 用户功能进度

源码已把所有现存 main-owned Agent 任务接入启动前自动选择：优先检测目标工作空间中的 Codex，
不可用时选择 Studio 已配置 API Key 且 executable 可用的 Claude Code。两者都不可用时返回两者
原因，需要续接的原生 Session、显式聊天和已开始执行的任务不自动迁移。产品明确请求新 Session
的后续 operation 会重新检测并选择，已有文章发布/图片调研不因复用会话 ID 而锁在旧默认。
此次没有发版，也没有重跑用户
原有“每日简报”或对任何真实账号提交文章。

审计入口包括主进程 `sendMessage`、`sendScheduledTaskMessage`、`requestInternalText`，后端
工厂、SDK 创建点以及 renderer IPC。没有发现其他绕过这些入口的自主文本 Agent 任务。
普通聊天/继续/压缩遵守显式会话绑定；远程 Agent 遵守远程工作空间协议。图片/视频供应商和
Pexels 素材检索是独立能力，不通过切换文本 Agent 代替其服务凭证。

| 用户能力                       | 原有缺口                            | 本轮证据                                                                         |
| ------------------------------ | ----------------------------------- | -------------------------------------------------------------------------------- |
| 定时任务（手动、到点、补执行） | 旧默认 Claude；首轮修复只固定 Codex | 真实 Electron + Codex 手动/到点成功，打开生成文件；Claude 自动备选实际调用链通过 |
| 文章发布执行                   | 未指定后端；执行身份在选择前取值    | 服务回归验证自动选择声明、最终 Codex 身份登记、原工具限制；未公开发布            |
| 图片调研                       | 未指定后端                          | 服务回归验证自动选择声明、四个受限工具及原账号绑定；未操作真实账号               |
| 视频智能分镜                   | 内部文本生成直接落入 Claude 默认    | 真实 Electron IPC + Codex 返回合法 3 场景提案                                    |
| 口播生成、精简、改写           | 共用内部文本入口遗漏绑定            | 真实 Electron IPC + Codex 生成 1 段口播提案；三个模式共用路径，模式规则单测通过  |
| 公司账目 AI 分类               | 内部文本入口遗漏绑定                | 导入临时测试流水后，真实 Electron IPC + Codex 返回待确认建议，未确认入账         |

真实 Codex 自动验收入口：

```sh
node scripts/scheduled-task-codex-smoke.mjs --internal-tasks
```

使用隔离 userData、临时工作空间和已有 Codex 文件登录，不读取用户正式任务材料。证据位于
`/var/folders/4z/030bqrj52qn9vpf4w6hydk_c0000gn/T/studio-scheduled-codex-ztjeKm`：
`result.json`、手动执行/产物/自动执行截图。测试工作空间已清理。

- 手动运行：`b86a5633-a89a-4c57-8e2e-6f269806e4a1`，生成 `reports/manual.md`。
- 到点运行：`b474a7e2-089d-44aa-9f7d-4f2a8986051d`，生成 `reports/scheduled.md`。
- 两次运行均 completed，主进程实际绑定 Codex、有原生 Session、流中有 `editor_read`，文件包含
  只存在于绑定资料中的标记。三个内部生成入口均观察到主进程 `selected=codex` 诊断并返回领域
  schema 校验后的提案。

自动备选验收入口：

```sh
node scripts/scheduled-task-fallback-smoke.mjs --claude-fallback
```

原生 Codex 使用临时空 `CODEX_HOME`，无登录；Studio 配置测试 Claude Key 和 localhost 拒绝
端点。任务自动选择 `claude-code`，真实 Claude SDK 请求到达测试端点；模型拒绝后保持 failed，
模板保存且可打开。该证据证明自动选择及执行入口，不证明真实 Claude 提供商的正常生成。
不加参数的同一脚本使用拒绝事件的 Codex 协议 fixture，原有模板/UI 回归也通过。

## 工程准备度与失败路径

- `pnpm verify` 通过，覆盖 450 个测试文件，3,907 项通过、14 项跳过，并完成类型检查和构建。
  其中 13 项覆盖自动选择 Agent 的会话链路，包括绑定中取消、内部生成超时和等待后端释放。
- 本轮随后补充“既有产品开启新 operation 时重新选择”的第 13 项用例；最终对自动选择、
  Session 信任、发布绑定和流投影运行 4 个文件共 75 项测试，全部通过，最终构建通过。
  这部分最终增量使用定向验证，未再重跑上面的全量 verify。
- 只读探测按目标工作空间检查配置，总预算 4 秒；不发模型请求、不开放任务工具。Claude
  备选要求已保存 Key、已解析运行时、无运行时故障和 executable 可执行；不继承系统登录。
- 准备期间复用既有 run 账本锁住配置和重复请求，临时控制器负责探测取消；取消、关闭会话和
  退出均不得迟到发送。发布在 `onRunPrepared` 读取最终身份并交给 WebAffair 登记。
- 实际绑定由主进程随现有流事件发送，renderer 只接受匹配活动 run 的事实，不按当前聊天猜测。
- 内部文本生成复用相同选择入口、禁止工具、失败结果不当正文；超时观察 Promise 拒绝并关闭
  会话，成功时等待后端收尾再释放。没有新增调度器、会话迁移或运行中重试循环。

## 真人复验与未完成项

1. 用包含修复的 Studio、已有 Codex 登录且不配置 Claude Key，创建读取测试文件的任务，执行
   并打开产物；再设置几分钟后的单次任务，保持 App 运行，核对自动触发与新产物。
2. 在隔离测试环境中让 Codex 未登录、配置可用 Claude，重复同一任务，核对实际 Agent 为 Claude。
   两者均不可用时确认错误分别说明两者原因，不能出现成功记录。
3. 从视频制作入口生成分镜和口播，在公司账目中对测试流水请求 AI 分类；确认获得可审阅提案，
   不把提案误当已应用或已入账。
4. 在 Agent 检测期间取消任务，确认不会随后启动模型或生成文件。保持原有只读和 create-only 边界。

检测通过仅说明启动前置条件满足；网络、额度、权限或平台状态仍可能在实际执行时失败。选定
后不自动重试其他 Agent。文章发布与图片调研的真实账号端到端验收仍未完成；发布闭环必须
另获具体账号与文章授权并实际提交核验，不以本轮入口和身份测试替代。
