# 本地朗读验收

日期：2026-11-16。环境：Apple M1、16 GiB、macOS arm64、Electron 43.1.1。

## 用户功能进度

已实现 MD 全文/选区、网页正文/选区、已完成对话消息正文的本地朗读，统一进入 Git 右侧、
时钟左侧的底栏播放器。支持暂停/续播、前后段落、点击段落、倍速、音量、音色、停止；
切换来源替换旧任务，切换标签保留任务，切换工作空间暂停，窗口重载不自动出声。

真实 Electron 自动化已验证实际模型合成及 `HTMLAudioElement` 的播放/暂停/结束事件，
不是用计时器模拟成功。真人对发音、韵律、音色偏好的听感签收尚未执行；本次未正式打包发布。

## 模型验证

固定 Kokoro-82M v1.1-zh，sherpa-onnx-node 2.0.1，CPU 2 线程。独立 Node 探针结果：

| 样本 | 音频时长 | 合成耗时 | 实时率（耗时/音频时长） |
| --- | ---: | ---: | ---: |
| 中文短文 | 5.72 s | 3.56 s | 0.62 |
| 中英文混读 | 5.45 s | 3.75 s | 0.69 |
| 日期、版本号与数值 | 11.18 s | 5.81 s | 0.52 |
| 较长中文男声 | 16.09 s | 7.88 s | 0.49 |

模型加载 0.92 s；样本进程 RSS 约 580–634 MiB；探针取消后进程在约 15 ms 退出。
这些是本机样本测量，不是跨设备性能保证。当前按有界段落预生成下一段，较长段落、较慢设备
或较高倍速仍可能出现缓冲等待；界面会显示实际生成状态。

首次下载约 348 MiB，安装约 407 MiB。真实播放器安装入口已完成官方固定包下载、SHA-256
以及 377 个文件校验。最终完整回归复用该已安装资源，并在启动时重新验证完整性。
模型只按用户点击安装；文档正文和音频不上传，应用不要求额外安装 Node/Python。

发现并修复的实际兼容问题：Electron 43 拒绝 sherpa 默认 external buffer；改用官方
`enableExternalBuffer: false` 后，在真实 utilityProcess 内成功产生并播放音频。

## 2026-11-16 自查修复

上一轮正常路径验收通过，不代表边界条件没有问题。本轮确认并修复了五类问题：

| 类别 | 修复前可复现问题 | 修复与验证 |
| --- | --- | --- |
| 播放状态机 | 重复继续把 playing 改成 ready，导致 ended 被忽略；暂停与 ended 交错会卡在已结束音频；迟到暂停把最终完成态改为 paused | 控制操作幂等；消费真实 ended 时保留暂停意图；3 个失败回归先复现再通过 |
| 并发与旧响应 | 停止后旧快照可以短暂重新启动音频；未完成的旧来源请求会一直阻止新来源播放 | 最新操作的快照确认后才恢复音频传输；旧操作不能阻塞新操作；2 个失败回归先复现再通过 |
| 网页正文提取 | 嵌套列表的子项读两遍，段落中的 aria-hidden 提示和按钮文字混入正文 | 改为按文本节点遍历，排除不可读子树；真实 Electron 页面已复现修复前重复与混入，修复后验证去重、排除和英文行内空格 |
| 首次使用入口 | 原生右键绕过 renderer 的 startTts 包装，缺模型时不自动显示安装提示 | 统一由快照阶段变化触发提示；验证首次打开且用户收起后不反复弹出 |
| 共用消息入口 | 按钮在远程/其他消息投影中可见，正文却只从本地会话 store 查找 | 从已展示且已完成的消息传递纯 text 正文，保留工作区校验；真实界面验证本地记录消失后仍可读；远程投影命令与共用组件测试通过 |

消息快照不引入远程域硬依赖，不发送远程请求；思考、工具调用与工具结果仍排除。
真正的远程账号会话朗读尚未实测；其结果不由投影/组件测试替代。
原生右键回调、安装提示和窗口内网页选区分别验证，真人右键完整手势仍按下文签收。

## 真人验收动作

1. 运行 `pnpm dev`。在任意 MD 的工具栏点击“朗读”；首次使用点击“下载并安装”，完成后
   点击播放器中的“播放”。验收：能听见正文，底栏来源正确，面板显示当前段落。
2. 在设置关闭 Markdown 自动保存，修改正文但不保存后朗读；再选中几句话点击“朗读选区”。
   验收：读的是当前编辑内容/选区，代码块只提示后跳过，不逐字读 Markdown 标记和链接地址。
3. 在内嵌浏览器打开文章，点“朗读正文”；选中文字后右键“朗读选中内容”。
   验收：正文不混入常见导航/页脚；无法提取的页面提示改用选区。仅处理已经加载的主页面内容，
   不承诺所有复杂网页、跨域 iframe 或尚未加载的内容都能自动识别。
4. 在一条已完成的对话消息旁点击“朗读”。验收：只读该消息的文字正文，不读思考块、工具
   调用和工具结果；接着点击 MD/网页朗读，确认旧来源停止，不同时播两份音频。
5. 在底栏暂停、继续、跳段、调整语速/音量/音色、停止；展开面板后操作按钮，再收起。
   验收：播放器位于 Git 右侧、时钟左侧；不同窗口宽度下不覆盖时钟，网页不挡住面板操作。
6. 切换标签继续听，切换工作空间确认暂停；重启应用确认不自动出声。模型装好且文档/网页
   已加载后断网，再发起朗读，确认仍能合成播放。

自动化已执行对应核心路径；断网用 Chromium 网络离线模式验证，未修改本机网络设置。
原生右键菜单回调及过期绑定由菜单测试覆盖，网页选区的真实合成由统一命令路径验证。
真人右键操作及主观听感请按上述动作签收，不将自动化记录冒充真人已验收。
