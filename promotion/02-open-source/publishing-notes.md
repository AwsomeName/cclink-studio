# GitHub 与开源社区稿使用说明

这一版面向愿意试用源码、复现问题或参与开发的读者。正文按“项目定位 → 当前能力 → 源码职责 → 启动与试用 → 参与改进”展开，保留操作条件和真实入口。

## 标题与摘要

主标题：CCLink Studio：连接文件、网页与 Agent 的开源桌面工作台

短标题：CCLink Studio：从本地文件开始的开源 AI 工作台

摘要：CCLink Studio 是面向 macOS 的开源 AI 桌面工作台，把本地文件、Markdown、浏览器、终端与 Agent 放在同一个工作空间。本地能力免费，免 CCLink 登录；模型账号与调用费用由用户自行配置和承担。本文介绍当前能力、源码职责、启动方式和参与入口。

## GitHub 与论坛排版

正文使用常规 Markdown 表格、代码块、图片和链接。若保留本文件夹结构，`images/` 相对路径可以直接使用；若复制到仓库其他目录，应同步修改图片路径。社区编辑器需要单独上传图片时，使用上表 PNG，再用平台实际返回的地址替换，检查四张图和图注是否完整。

在 GitHub 上检查表格与命令代码块；在论坛编辑器中再检查图片缩放、标题层级、链接与手机显示。本地预览通过不代表目标平台排版已经核对。

## 应保留的条件

- “免费”与“免登录”指 Studio 本地能力；模型账号、API 和费用条件不可删去。
- 当前完整工具 Agent 基于 Claude Code。本机或自定义运行时可使用自身认证；内置 Runtime 使用用户在 Studio 中配置的 Provider API Key。
- Node.js 22 来自当前仓库 CI，pnpm 11.5.0 来自 `packageManager`；命令与图卡是上手说明，本轮没有重新执行全新机器安装。
- 真实界面来自开发版 v0.1.118，使用演示文件，Agent 指令尚未发送；不能把截图改标成当前发行版或执行成功记录。
- 数据源与 Android 连接保留各自环境条件，网页操作保留页面、账号和人工参与范围。

后续仓库变更时，先复核环境配置和界面，再运行 `node promotion/tools/build-open-source.mjs` 更新图文。素材记录见 [事实与图片来源](../sources.md)。
