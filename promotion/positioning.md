# CCLink Studio 宣传定位

## 一句话介绍

CCLink Studio 是一款开源、本地优先的 AI 桌面工作台，把网页、文档、文件、终端和 AI 协作放进同一个工作空间。

## 核心读者与入口场景

首批重点介绍给内容创作者、独立开发者和愿意自己配置 AI 工具的用户。

最容易理解的入口是一篇文章的准备工作：打开本地文件夹，浏览参考资料，整理 Markdown 草稿，再根据需要配置 Agent，通过工具协作处理材料和文档。

读者看完应能说清三件事：这是桌面应用；本地工作空间连接常用工具；Agent 可以通过工具参与文档和网页操作。

## 对外表达顺序

1. 先讲反复切换工具、搬运资料和解释背景的具体麻烦。
2. 再讲工作空间如何容纳材料、操作和结果。
3. 展示真实文档、浏览器和 Agent 入口，说明协作方式。
4. 交代本地能力免费免 CCLink 登录，模型服务自行配置并承担费用。
5. 给出源码入口，邀请试用、反馈和参与。

## 必须保留的准确性

- 产品名称统一为 CCLink Studio。
- 许可统一为 GPL-3.0-only。
- “免费”限定为 Studio 的本地能力；模型账号、API 和调用费用另行配置与承担。
- “免登录”指免 CCLink 账号登录，不代表第三方网站或模型服务免认证。
- 当前完整工具 Agent 以 Claude Code 后端为基础，不承诺任意 Agent 和任意 API 都能直接替换。
- 当前宣传的桌面目标平台为 macOS，不写成全平台已交付。
- 本地优先不等于所有 AI 数据永远不离开本机；正文不作全离线和数据零外传承诺。
- 网页操作受用户授权、站点登录与页面条件限制，不承诺任意网站自动完成。
- 截图中的指令停留在输入框，必须写成任务准备界面，不能作为模型已经执行成功的证据。

文章发布、公司经营、视频创作、硬件生产和远程工作可按专题另行介绍。加入主宣传稿前，先逐项核对当前实现、具体使用条件和真实验收证据；导航入口本身不证明业务闭环。

## 本轮可执行验收

1. 打开 `index.html`，能进入四套图文预览。
2. 每套都有完整正文和实际图片，图片与相关段落相邻。
3. 公众号稿能辨认真实界面与流程示意，社区稿有可执行的源码启动命令。
4. 官网稿有可直接取用的标题、简介、功能文案和行动入口。
5. 社交媒体有可单独使用的 PNG 图卡及对应短文。
6. 本地图片无缺失，正文与图片没有宣称本轮未执行的模型结果或平台发布结果。
