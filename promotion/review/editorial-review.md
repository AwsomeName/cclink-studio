# 宣传稿逐项审阅

## 本轮结论

现在可以审阅和修改公众号、GitHub／开源社区两套精修图文；官网与社交媒体仍为初稿，尚未公开发布。共用素材包括两张真实界面截图和七张初稿配图，另有五张公众号、四张社区专用配图。

本轮交付是宣传材料；截图展示界面和任务准备，不把它们包装为真实模型执行或平台发布的验收结果。

## 逐稿拷问

| 稿件 | 最关键的假设 | 本轮处理 | 下一轮最值得确认 |
| --- | --- | --- | --- |
| 公众号 | 读者能从写作场景理解桌面工作台 | 精修 21 个正文段落与一条任务示例，围绕同一篇文章展开；补充工作台导览、真实局部特写和竖向分工图 | 补一段真实 Agent 执行并保存文档的录屏；发起人的个人经历须由本人提供 |
| 开源社区 | 读者愿意从源码试用，能理解 Agent 运行时配置 | 精修 17 个正文段落、5 行核心能力和 3 个试用动作；新增真实工作台、源码职责与上手顺序专用图 | 在一个明确配置的环境补齐源码启动、Agent 调用工具与文件回读的录屏 |
| 官网 | 首页应迅速讲清产品与下一步 | 分离首屏、功能、使用条件与行动入口，链接指向源码和上手说明 | 未来官网实现时，按真实下载入口与当前版本替换行动入口 |
| 社交媒体 | 图卡被单独转发后仍要保持准确 | 统一名称、品牌和使用条件；提供方形封面与三图顺序 | 根据实际发布平台调整首图裁剪和第一句话 |

## 完成度边界

- 两张原始截图来自真实 Studio 窗口，没有模拟 Agent 输出。
- 文档已经在真实编辑器中打开，浏览器已经实际加载原创演示网页。
- 本轮没有发送模型指令，因此没有宣称这两张截图证明 Agent 执行成功。
- 数据源和 Android 在正文中保留环境条件，没有追加这些域的业务验收结论。
- 所有对外正文区分本地免费能力与用户自配模型服务，没有全平台、全离线或任意网站成功承诺。
- 平台上传、公众号后台排版、正式官网部署与公开发布不属于本轮已经执行的结果。

## 检查记录

配图生成后逐张检查中文、图卡边界、图注与截图内容。界面图卡首轮因原生采集实际返回 JPEG、却按 PNG 媒体类型嵌入而没有显示截图；已保留 JPEG 原字节、更正扩展名和媒体类型，重新生成并目视确认。

本地素材检查通过：全部本地引用可解析，编辑配图与两张真实截图的格式、尺寸及校验值一致，四套正文都有实际配图。详见 [素材检查结果](verification.json)。

四套预览分别在 1280px 桌面宽度与 390px 手机宽度下检查通过：图片全部加载，页面无横向溢出；手机正文为 17px。浏览器尺寸已恢复默认。详见 [排版检查结果](layout-verification.json) 和同目录预览截图。

这些检查只核对宣传资料，不代替 Studio 功能测试或真实模型验收。公众号等平台的后台裁剪与排版仍需在实际发布界面确认。
